# Ignored execution scratch

Markdown Planning and committed source remain authoritative. `.runs/` is local, ignored evidence: a fresh clone does not contain it. Keep new TASK execution material in `.runs/tasks/<TASK-ID>/runs/<run-id>/`, experiments in `.runs/prototypes/<TASK-ID>/<experiment>/`, and retired material in `.runs/archive/<batch>/<original-relative-path>`. Allocate unique run IDs rather than overwriting another run. Keep an archive manifest outside the retired source with its checkout identity, old/new paths, SHA-256 file digests and exclusions. Check ownership, live handles, symlinks, collisions, source identity and reference consumers before moving; compare digests after. Do not treat the archive as a backup shared between clones.

Tool-owned output keeps its required stable location (`.runs/build/`, `.runs/client/`, `.runs/backend-coverage/`, `.runs/composer/`, `.runs/openapi/`, `.runs/validations/`, `.runs/https/` and guarded test output) while its producer needs it. Independent Review and QA publish canonical reports at the **base worktree's** `.runs/reviews/<TASK-ID>/review.md` and `.runs/qa/<TASK-ID>/qa.md`; their run histories, captures and attached evidence remain with their owning reports. The Engineer may read its TASK's canonical reports but does not publish or edit them. Preserve worktrees via Git and mounted/running resources via their owners, never by ordinary file moves. Existing `notes/`, `land/`, `landing/`, `handoffs/`, `planning/` and older task-named folders may contain historical receipts or active consumers; these are exceptions pending ownership/retirement checks, not templates for new material. Do not move credentials or signed/hashed reports to normalize a tree.

When moving an artifact, repair present-tense navigation in Planning, docs, instructions and scripts. Preserve historical commands, original signed receipt paths and original source identities; add a current locator or relocation manifest rather than rewriting history. Audit Markdown links and anchors **and** code-span/plain-text and absolute checkout paths, including archived Planning and Wayfinder records. Classify templates, remote URLs, historical locators and missing local evidence instead of calling every syntactically valid link a valid artifact. Review and QA independently check the actual intended target against the manifest, not only the Planning validator's link check. Unknown ownership or unverifiable references remain explicit exceptions and block claims of a complete cleanup.
