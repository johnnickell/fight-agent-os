# Inspect protected GitHub publication feasibility

## Outcome

An authorized human obtains bounded read-only GitHub publication facts for the complete creation preview before
an attempt or local repository exists. Actual identity, owner policy, target availability and transport capability
are distinguished from stale, denied, unavailable or unknown facts without exposing credentials or reserving a name.

## Scope

- In scope: Protected API/console preflight, narrow GitHub read adapter, safe current-identity/owner/target/policy/
  transport facts, bounded observation provenance and actionable operator guidance.
- Out of scope: Account enrollment/login/repair, key creation, credential collection, private-starter access,
  repository creation, attempt admission, local Git mutation, browser form and a general provider proxy.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect selected publication | N/A — explicitly authorized read-only inspection | Existing authenticated identity, exact owner/name/visibility policy and supported transport | N/A — observations confer no authority | Bounded provider reads and safe preview facts; no reservation or publication |
| Explain unavailable access | N/A — read-only | Safe scoped failure, freshness and applicable guidance | N/A | Actionable denied/unknown/unsupported result, no enrollment or repair |
| Inspect retained status | N/A — ordinary read | Authorized retained observation and provenance | N/A | No live provider call, authentication or refresh |
