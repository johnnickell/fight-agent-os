# Explicitly create or apply reviewed Planning changes

## Outcome

An authorized human explicitly creates or applies a reviewed single-artifact Planning candidate through the same
semantic operations as direct editing, or receives a preserved conflict with no false acceptance. Exact
proposal/version acceptance linkage makes lost-response recovery inspect committed Planning state rather than
repeat a mutation; it does not require an immutable original-response journal.

## Scope

- In scope: Exact candidate review/confirmation, supported semantic create/revision composition, current authority
  and revision checks, atomic accepted state/audit/intent, safe committed-result inspection and recovery.
- Out of scope: New Planning domain/allocator, whole-document replacement, atomic decomposition batches owned by
  TASK-00359, automatic acceptance, lifecycle bypass, template publication, coding execution or Git effects.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Review exact change | N/A — protected preview | Complete candidate version, proposed semantic changes, current constraints and expected revisions | N/A | Inspectable human intent; preview grants no mutation authority |
| Create or apply | Explicit human semantic command/orchestration with stable identity | Revalidate candidate, actor, scope, mode and all affected revisions | Actual owning Planning events and accepted proposal linkage | Complete approved change and required audit/intent, or rollback |
| Resolve uncertain apply | Original-command reconciliation where needed; ordinary reads remain queries | Actual committed result, identities and current visibility | Only confirmed owning facts | Original outcome before another Apply is offered; no mutation replay from GET |
