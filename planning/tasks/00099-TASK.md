# Map complete Markdown baseline events

## Outcome

One exact immutable source manifest deterministically maps into preserved human references, newly minted typed COMB identities, stable child identities, complete relationships and one self-contained imported-baseline event per Planning aggregate, with every authored byte and historical meaning accounted for before any database import.

## Scope

- In scope: Versioned manifest-to-baseline mapping application capability; immutable mapping identity/revision/digest; deterministic one-time injected COMB allocation retained across same-source retry; existing human references/slugs; stable identities for criteria/decisions/use cases/evidence and other children; Wayfinder map/ticket, ResearchNote, Prototype, Epic, Ticket and Task baseline payloads; standalone kinds; lifecycle/archive; hierarchy/dependencies/order/queue overrides; criteria/evidence/delivery/PR/completion links; recognized typed/narrative sections; ordered supplemental unknown sections; unclassified catch-all authored bytes; complete authored Markdown excluding generated blocks; source path/commit/tree/file/semantic digests and migration actor/time provenance; complete mapping/report Views and validation.
- Out of scope: Manufacturing historical semantic events from Git, writing event streams/projections, rehearsal database, status/content/link repair, warning waiver, changing authority, Markdown editing, browser UI and reusing prototype SQLite schema or UUIDv5 identities.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Build baseline mapping | Prepare complete import mapping from exact manifest | Preview mapped identities, typed state, relationships, ordering and content accounting | N/A — mapping emits no authoritative Planning event | Immutable proposed identity/payload mapping and complete report are retained as migration evidence only |
| Retry same mapping | Repeat with same manifest/mapping command identity | Compare prior mapping/digests and importer version | N/A — retry emits no Planning event | Original COMB identities and exact mapping result return idempotently rather than reallocating |
| Reject ambiguous source | N/A — failed mapping | Explain duplicate/unknown/missing/unsupported/unclassified semantic facts | N/A — failure emits no Planning event | Complete blockers are reported; no event stream or authority state is written |

## Validation and permissions

Consume only TASK-00098's immutable supported manifest and revalidate its digest/schema/classifier/source provenance. Mint each Fight Common `Uuid::comb()` identity once through an injected generator, retain it in the immutable mapping, and return it on same-source/idempotent retry. Preserve all existing EPIC/TICKET/TASK/WF references and map slugs exactly under TICKET-00026 uniqueness rules. Never allocate a replacement silently for a collision or malformed reference.

Produce one versioned self-contained imported-baseline event payload per aggregate root using that aggregate's TICKET-00026 schema. The event represents current imported baseline, not fictional historical edits. It includes typed fields/relationships/children, recognized narrative, ordered supplemental unknown sections, unclassified catch-all content, complete authored Markdown excluding regenerable generated blocks, and source provenance/digests. Git commit/tree/path preserve legacy edit provenance; do not replay Git history into invented Domain events.

Map every live/archive Wayfinder map/ticket/decision/frontier/handoff, research/prototype link/verdict/artifact tombstone, EPIC/TICKET/TASK hierarchy/kind/lifecycle/archive, stable use case/criterion/evidence, dependency, Roadmap/TASK order/override, delivery/PR/completion evidence and other accepted current semantics. Generated views become expected projections only. Repository files must not be required to reconstruct aggregate state after import or later prototype artifact purge.

Resolve every parent, dependency and typed link against the complete mapping. Validate same-Repository/workspace boundaries, cycles, statuses, references, child identity/order, closeout/archive invariants, authored-content coverage and schema versions. Unknown lifecycle, duplicate/missing identity, unresolved relationship, unsupported semantic value, content loss or unclassified ambiguity is fatal; there is no waiver or best-effort repair. Formatting-only/generated differences may be reported explicitly but never hide authored loss.

Require migration-preview Permission and current Repository/context. Mapping evidence is operational migration authority, not aggregate history or approval. Safe reports may show references/section labels/counts/digests but not complete source payload, secrets, absolute paths, internal IDs unnecessarily or hidden linked records.
