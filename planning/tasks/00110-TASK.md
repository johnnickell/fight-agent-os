# Operate guarded lifecycle and relationship work

## Outcome

Authorized users can preview, confirm and execute exact lifecycle, closeout, Won't Fix, relationship, waiver, archive and restore commands with complete server-provided impact and stale recovery, while no client interaction cascades state, removes dependencies or bypasses required human judgment.

## Scope

- In scope: Intent-specific ready/info/human/start/complete/reopen transitions exposed for direct Planning; TICKET/EPIC closeout; TASK Won't Fix impact-plan presentation/classification/resumption; Wayfinder close/reopen where exposed; typed reparent and dependency add/remove; evidence criterion waiver; archive eligibility/action; archive browse restore prerequisites/action; exact expected revisions and confirmation tokens; server preview/reason/impact mapping; permission-aware controls; confirmation dialogs/forms; stale/partial/denied/conflict recovery; API services/components/catalog/accessibility evidence.
- Out of scope: Generic status setter, automatic parent/child/dependency cascade, coordinated work start/claim/Runner selection, multi-record agent proposals, manual Blocked/Hold, client-computed cycle/closeout/impact rules, source deletion/retirement, provider status mutation and browser conversations.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Transition/close/reopen | Dispatch exact type/intent command | Preview prerequisites, children, criteria/evidence, scope and current revisions | Owning semantic lifecycle/closeout event | Server-confirmed transition only; parent/children remain unchanged unless exact command contract says otherwise |
| Mark TASK Won't Fix | Dispatch decline command after impact-plan decisions | Query direct/transitive dependents and current plan/edge versions | TASK declined event; separate dependent events only via separate commands | No cascade/removal; interrupted plan remains recoverable and revalidated |
| Reparent/change dependency | Dispatch exact relationship command | Preview endpoints, lifecycle/active links, cycles and downstream impact | Relationship semantic event | One valid relationship changes; ownership/reference/status remain as defined |
| Waive criterion | Dispatch exact human-confirmed waiver | Preview unmet intent/evidence/downstream closeout impact | Criterion waiver event | Explicit reasoned waiver appends and remains distinct from satisfaction |
| Archive/restore | Dispatch type-specific command | Preview terminal/child/parent/link/retention prerequisites | Archive/restore event | Visibility state changes only; no completion/deletion/reopen cascade |

## Validation and permissions

Render action availability/reasons from server Views only. Client may organize and confirm but never decide allowed transitions, closeout readiness, graph cycles, dependent classifications, waiver validity, archive eligibility or restore prerequisites. Every command carries exact aggregate/constraint/relationship/plan versions plus server-issued confirmation where required.

Confirmation copy identifies artifact/reference, exact action, important child/dependent/evidence/retention impact, actor and expiry. Human-required operations cannot be presented as agent/system approval. Stale/expired confirmation or changed impact returns to preview and preserves authority. Dangerous action appearance alone is not security; distinct server Permissions remain authoritative.

Won't Fix flow shows bounded direct and transitive active dependents, then requires human classification for each direct dependent under TICKET-00026. Each resulting edge removal/Needs Info/separate decline is an explicit command and progress is recoverable. Never collapse into one client cascade or hide unprocessed effects.

Reparent/dependency forms use safe typed candidate queries and explain hidden/unavailable endpoints without enumeration. Cross-Repository TASK dependency/replacement requires visible Workspace authority and explicit scope; no arbitrary reference/URL establishes relationship. Active delivery/execution links surface required confirmation.

Archive is orthogonal to status and current/archive routes. Preview terminal/child/parent/link/retention requirements. Restore may require parent restoration but never silently performs it; reopening is separate. No archive UI deletes files, artifacts, events or conversations.

Cover loading/denied/not-found/stale/expired/partial impact/conflict/unavailable/offline and uncertain outcomes. On rejected/provisional actions, restore current server state and focus/announce explanation. No optimistic final card/detail state before command success.
