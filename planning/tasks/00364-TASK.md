# Conduct bounded AFK Planning preparation

## Outcome

An authorized planner can leave a bounded research/prototype preparation operation running and return to truthful
activity, interruption and reviewable findings. Actual supported work uses existing protected execution and evidence
owners; it stops at human choices and cannot promote prototype code or fabricate progress.

## Scope

- In scope: Browser admission/observation of bounded AFK preparation, actual supported execution composition,
  real stages/last activity, interruption/recovery and human-reviewed findings through existing candidate/Apply.
- Out of scope: Another Runner/sandbox/provisioner, general browser automation or web crawler, unrestricted shell
  networking, coding Workflow launch, autonomous product decisions, code promotion and proof-only execution routes.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Begin bounded preparation | Existing authorized assignment/attempt operation for eligible decision | Exact question, roots/effects, limits, tool and host readiness | Owning admission/attempt facts | Only supported bounded research/prototype work, not automatic scope expansion |
| Observe activity or recover | Explicit owning stop/recovery where requested; ordinary status is read-only | Actual queued/inspecting/running/preparing/review/interruption facts and last activity | Existing execution/recovery facts only | Honest status and original-work recovery, never duplicate launch |
| Review findings | Existing explicit candidate correction/Create/Apply | Sources, findings, verdict, cleanup owner and verified durable references | Owning accepted research/prototype/decision facts | Accepted findings only, never authoritative prototype code |

interrupted/failed states and last activity, not percentages inferred from tokens/turns/time. Unknown liveness is
unknown, and a powered-off host does not execute. Disconnect/logout detaches while current revocation controls
subsequent use. Stop/recovery reconciles original processes/effects and liability before any safe continuation.
