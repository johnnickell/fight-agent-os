# Bind and fence separately confirmed cleanup authority

## Outcome

The creation owner admits separate cleanup consent only for an exact current impact, with real resource/reference
exclusion shared by stage and cleanup participants. Effect adapters receive an immutable bounded authorization,
not permission inferred from creation, failure or cancellation.

## Scope

- In scope: Protected cleanup confirmation/admission/result contracts, exact impact binding, current resource/
  reference checks, durable exclusion and original outcomes through the existing attempt owner.
- Out of scope: Final browser impact inspection, local/provider deletion, automatic compensation, new retention
  engine, deleting registration/profile/context history or a separate attempt state machine.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Confirm exact cleanup | Separate current-authorized cleanup confirmation | Verified exact impact, resources, references and quiescence evidence | Committed cleanup-consent/intent facts | Durable exclusion and bounded original cleanup operation, no deletion |
| Check admitted scope | N/A — protected read/participant check | Exact consent, expected state, current ownership/references and operation | N/A | Permission to proceed only through the qualified owning adapter |
| Record original cleanup result | Matching expected-state cleanup-result operation | Verified removed/retained/uncertain resources | Attributed cleanup facts | Truthful partial/complete/held result; history retained |

remain independent. Qualified explicit never-run preparation is distinct from unknown process state. Release
exclusion only against verified original disposition; lost acknowledgements cannot retarget a reused path/name,
