updates planning records. John authorized implementation in an isolated worktree on 2026-11-01 after the
TASK-00553 run audit found repeated full builds following task-only completion notes.

## Scope and acceptance criteria

- [x] Exclude ordinary Markdown planning records and generated planning views from the application fingerprint;
      keep governing instructions, ADRs, templates, non-Markdown planning files, symlinks, code, dependencies,
      other documentation, runtime and generated artifacts covered.

      or changing planning fails the invocation; an application miss still runs the complete application gate.

      Report fresh planning separately from reused application evidence; reuse does not accept new requirements.
- [x] Explain bounded cache-miss categories and elapsed planning/fingerprint/evidence/phase times without
      exposing environment values or introducing another evidence ledger.
