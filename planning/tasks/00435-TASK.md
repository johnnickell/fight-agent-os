# Review instruction suggestions in the existing Dashboard form

## Outcome

A human can request bounded instruction help, discuss intent, reconnect to the original durable proposal and
explicitly adopt suggested text into the existing Dashboard form. A separate human Save uses the same current-state
mutation path as direct editing, never an Agent submission or an automatically restored browser draft.

## Scope

- In scope: Existing viewer/form assistance controls, durable question/proposal presentation, full diff/provenance,
  explicit adoption, late/stale/conflict handling, original request recovery and real proposal-to-Save integration.
- Out of scope: Another chat/editor/workspace, provider/session/Skill owner, filesystem write API, persistent manual
  drafts, autosave, co-editing, automatic AI merge/replay, publication/sync and new Agent roles.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Ask for help with selected file | TASK-00434 explicit assistance submission | Current safe selected base/context, actual Agent/model readiness and disclosure limits | Owning admitted input facts | Bounded request, no filesystem change |
| Answer a clarification | Existing exact-question serialized human reply | Original request/question and current authority | Owning accepted-input facts | Durable answer, not approval of file mutation |
| Inspect or reconnect | Read original request/proposal; explicit owner recovery when needed | Current visibility, complete proposal/base diff, usage and lifecycle | No event for ordinary read | Same durable history without another paid request |
| Use suggested content | N/A — explicit human form adoption | Original/current base and diff, current Update authority, draft revision | N/A — no authoritative file effect | Volatile editable form content only |
| Save reviewed form | Existing TASK-00432 command through TASK-00433 | Exact current diff/base/context and verified optional proposal provenance | Existing verified Save facts | Human-authorized local effect, not publication or Agent continuation |
