# Save, delete and reconcile exact instruction-file changes

## Outcome

An authorized human can create, replace or explicitly delete one recognized root instruction file through a
production API, inspect the original operation and reconcile interruption without overwriting intervening work.
Verified local outcomes feed existing context/session currentness owners; Save grants no publication or AI authority.

## Scope

- In scope: Exact Save/Delete previews and commands, durable original intent/outcome and protected delivery,
  expected-absence/digest mutation, current custody/physical fences, result observation, recovery and drift integration.
- Out of scope: Browser form, AI generation, another identity/custody/session engine, arbitrary files, Git publication,
  branch switching, synchronization/fetch, automatic merge/rollback, Pi reload and Agent continuation.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Preview exact change | N/A — bounded read | Original/current content, complete diff, effective-file consequence and actual target availability | N/A — no reservation | Safe scoped preview, no durable draft or filesystem mutation |
| Save complete content | Explicit Save with exact filename/content and expected digest or absence | Fresh authority/target/custody/base; original operation | Committed admission and verified mutation/outcome facts | One admitted local creation/replacement, no Git publication |
| Delete selected file | Explicit confirmed Delete with expected digest | Complete deletion diff and remaining-effective-file consequence | Committed admission and verified deletion/outcome facts | Exact selected-file removal only |
| Inspect conflict/outcome | N/A — read-only | Original operation and currently authorized safe content/Git evidence | N/A for observation | Conflict, verified result or explicit unknown; no replay |
| Reconcile interruption | Original-operation reconciliation; only independently proved-safe remaining delivery | Original intent, physical target, actual result, current authority and retained ownership | Confirmed original outcome/hold facts | No blind retry, duplicate effect, adoption or inferred rollback |
