# Inventory immutable Markdown Planning source

## Outcome

An authorized migration preview can inspect one contained committed Repository checkout and return a bounded immutable manifest that accounts for every live/archive Planning file, recognized aggregate, template, authored/generated block, reference, relationship, link and source digest without changing files, database Planning state or authority.

## Scope

- In scope: `InspectMarkdownPlanningSource`; designated-checkout/approved-root/Git evidence; exact source commit/tree and dirty-state checks; canonical contained file discovery for Planning roots/live/archive/templates/indexes/boards; file/path/byte bounds; symlink/special-file rejection; frontmatter/reference/status/parent/dependency/link discovery; template inventory-only classification; authored versus recognized generated-block classification; exact per-file/content/semantic and complete-manifest digests; generated/source provenance; immutable safe manifest storage/reference where required; migration-preview Permission; safe report/API/console output; direct comparison with accepted WF-011 prototype rules.
- Out of scope: Mapping COMB identities/events, importing PostgreSQL, modifying/normalizing Markdown, running generated-view writers, status/content repair, authority freeze/switch, browser UI, promoting the disposable Python/SQLite prototype and interpreting arbitrary prose as policy.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect a migration source | N/A — read-only source inspection | `InspectMarkdownPlanningSource` | N/A — inspection emits no Planning event | One immutable bounded manifest/report is returned or safely retained as migration evidence; source/authority remain unchanged |
| Reinspect unchanged source | N/A — read-only source inspection | Inspect the same Repository/commit/tree under the same classifier version | N/A — reads emit no Domain event | Equivalent file classifications and digests result deterministically |
| Reject an unsafe source | N/A — failed inspection | Explain dirty/mutable/outside-root/symlink/unknown/duplicate/broken source facts | N/A — failure emits no Domain event | Actionable safe diagnostics identify the blocking class without partial authority state |

## Validation and permissions

Resolve Repository, designated Checkout/Worktree, approved root and Git common-directory evidence server-side through TICKET-00024. Require a clean committed source, exact commit/tree and stable observations before/after reading. Canonicalize every path under approved Planning roots; refuse symlinks, special files, escape, duplicate canonical paths, source mutation during read, unsupported encodings and configured file/count/byte excess. Do not invoke a write-capable Planning formatter/checker during inspection.

Inventory live and archive locations even when empty. Classify templates as inventory-only and never as aggregate roots; placeholder links inside templates are not historical relationships. Recognize current EPIC/TICKET/TASK, Wayfinder map/ticket, research-note and prototype locations plus authoritative metadata. Treat boards, indexes, child tables and delimited generated blocks as projections under an explicit classifier version. Unknown files/sections/blocks remain visibly unclassified rather than silently ignored.

Record exact relative path, mode where relevant, size, byte digest, authored/generated ranges, parsed frontmatter/reference/status, discovered typed parent/dependency/link tokens and safe diagnostics. Manifest digest covers ordered file entries, source commit/tree, Repository/check-out evidence and classifier/schema versions. Semantic digest excludes only explicitly regenerable generated content; retain exact authored bytes/digests for later loss checks. Do not parse arbitrary narrative into status, relationships or authority.

Inspection writes no Planning aggregate/event/configuration/mode and edits no Git file. If durable manifest evidence is retained, it belongs to a separate migration-preview authority with immutable content-addressed identity, not imported Planning history, and its persistence must not imply approval. Require migration-preview Permission plus Repository/context currentness; safe Views omit absolute paths, source contents, secrets, credentials and inaccessible links.
