# Run the staging application behind real HTTPS

## Outcome

John can reach the actual core Fight application at `https://staging.fight-agent.dev`, served from the exact CI
artifact on an isolated SFO3 application host with private local PostgreSQL and real public HTTPS. This supplies
a useful staged browser/API target and early service interfaces, not a claim that all background integrations,
production capacity or the final browser Planning journey are qualified.

## Scope

- In scope: Fight-specific staging runtime composition, separately authorized target preparation, public ingress/
  TLS renewal, database/secret/network isolation, explicit schema and lifecycle procedures, real browser/API probes
  and safe operator guidance outside the application.
- Out of scope: TASK-00525's complete service/diagnosis integration, production target creation, artifact rebuilding,
  workstation trust changes, new security policy, real mail/backup engines, first-production promotion/cutover,
  coding-Agent execution, candidate builds on application hosts or a generic infrastructure platform.
