# Control Workflow visibility without hiding running work

## Outcome

Authorized operators can Archive/Restore Workflow visibility through API/console without changing execution or
hiding active work. This early visibility/current-membership and independent-running safeguard supplies
TASK-00387 without depending on completed search, Dashboard, usage or forecasting.

## Scope

- In scope: Owning revision-checked visibility operations, original-command results, safe membership queries,
  independent running visibility and actual consistency participants for source transitions and consuming queries.
- Out of scope: Browser components, a second Workflow engine, execution/claim/grant/Planning lifecycle changes,
  retention cleanup, per-user preference platform, usage facts and full Dashboard projections.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Archive visibility | Explicit expected-state Archive with active-work confirmation where applicable | Current Workflow/visibility, authority and running safeguard | Committed visibility fact, not execution transition | Current/Archived membership changes only |
| Restore visibility | Explicit expected-state Restore | Current visibility and original operation outcome | Committed visibility fact only | Current membership restored without resuming work |
| Inspect original result or running work | N/A — read-only | Protected operation result and bounded independent running/detail query | N/A | Honest membership/outcome and safe detail reference; no repair |
