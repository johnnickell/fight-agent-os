# Preview and admit exact instruction publication

## Outcome

An authorized human can preview and separately confirm one exact instruction-file PR publication through a
production API. A coherent immutable plan and durable original operation bind consent to the selected change,
registered target and actual custody; no Git effect occurs merely from preview or admission.

## Scope

- In scope: Read-only publication preflight, complete effect preview, explicit confirmation/admission, original
  operation/status/stop contracts, early stage intent/outcome participants and shared custody/currentness composition.
- Out of scope: Git branch/index/commit/push/PR/return execution, browser form, another scheduler/custody registry,
  source-host enrollment, AI, managed Review/Release Manager, sync/fetch and destructive recovery.

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Preview selected change | N/A — explicitly authorized read-only preflight | Safe selected diff, baseline/ownership, remote/default/native provider identity and capability | N/A — observation is not reservation | Complete bounded plan or refusal; no fetch, Git mutation or PR |
| Confirm exact plan | Explicit expected-state publication admission | Fresh authority, complete expected plan and real resource participants | Committed original operation/admission/audit/intent facts | Durable operation and exact ownership, no external work inside transaction |
| Admit or reconcile a stage | Narrow owning stage participant composed by actual stage consumer | Original intent, current scope/generations, prior verified effects and actual custody | Matching stage intent/outcome/hold facts | Durable effect authority before delivery; only verified original results advance |
| Inspect or stop original operation | Read original status; explicit stop command | Current authorized scope, original identity and remaining obligations | Committed stop fact when applicable | Prevent subsequent effects, not rollback or proof of process absence |
