# Rebuild, redact and render Planning authority

## Outcome

Operators can rebuild all TICKET-00026 Planning views and command-critical projections exactly from authoritative streams, narrowly authorized responders can tombstone prohibited content without disguising history, and authorized users can render deterministic read-only Markdown that cannot become an ordinary update path.

## Scope

- In scope: Bounded resumable projection rebuild application operation and checkpoint/state; all TICKET-00026 current/detail/hierarchy/history/constraint projections; exact equivalence/atomic replacement strategy; projection schema/version compatibility and unavailable state; narrowly authorized emergency content-payload redaction command/event/effect with actor/reason/original digest/redacted replay placeholder; projection/search/export/cache cleanup and documented backup-retention handoff; deterministic Twig Markdown representation queries/templates for Wayfinder maps/tickets, research notes, prototypes, EPICs, TICKETs and TASKs; authority mode, aggregate revision and template version markers; safe API/MCP/terminal-ready output; Permissions/diagnostics/PostgreSQL evidence.
- Out of scope: Generic editing/deletion, rewriting event identity/envelope/history, ordinary evidence correction, automatic redaction, backup-system implementation, Markdown ingestion/import/cutover, Board/Roadmap/queue rendering, React UI, tests of Twig/Doctrine/tool mechanics and asynchronous search infrastructure not otherwise required.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Rebuild projections | Explicit guarded rebuild operation | Inspect stream horizon, projection schema/checkpoint and progress | N/A — replay emits no Domain events | New projection generation replays deterministically and becomes readable only after successful complete validation |
| Resume/abort rebuild | Explicit operational control | Inspect checkpoint, failure and active generation | N/A — operational state is not Domain history | Work resumes safely or abandons only incomplete generated state; authoritative streams remain unchanged |
| Emergency-redact prohibited content | Narrow redaction command | Preview payload identity/digest, affected views/exports and backup obligations | Explicit redaction/tombstone authority record | Prohibited payload becomes an attributed placeholder across replay/views/exports while event identity/envelope/version remain |
| Render authoritative Markdown | N/A — deterministic representation query | Query typed current Planning View plus authority/revision/template version | N/A — rendering emits no Domain event | Copy-ready bounded Markdown is returned read-only and cannot be submitted as ordinary aggregate replacement |

## Validation and permissions

Rebuild reads authoritative streams through declared contracts in deterministic aggregate/version order and writes a separate generation/checkpoint. Validate event schemas, sequence continuity, payload digests/redaction placeholders, parent/reference/graph/lifecycle constraints and projection counts before atomically selecting the generation for reads. Failure leaves current proven projections active and exposes safe diagnostics; it never truncates streams or mixes partial generations. Command-critical projections are rebuildable but remain transactionally current during ordinary commands.

Emergency redaction is exceptional, not revision. Require a narrowly scoped Permission and exact human confirmation bound to actor, aggregate/event/payload identity, current digest, reason, affected outputs and expiry. Preserve event/aggregate identity, stream version, timestamp, original digest, actor and an explicit redacted replay placeholder while irreversibly removing prohibited content from primary payload storage, current/history/display/search/export/cache representations. Append/retain authoritative redaction evidence without creating a false ordinary event history or breaking replay. Document and trigger owned backup-retention handling honestly; do not claim immediate deletion from immutable external backups without evidence.

Render only from typed current Views through type-specific deterministic templates, never directly from arbitrary event payloads or client Markdown. Output identifies Repository-local human reference/slug where applicable, aggregate revision, database authority mode and template version. Escape/normalize unsafe content consistently, bound output, include supplemental content labels and omit secrets/internal IDs as required. Template changes advance template version but do not mutate aggregates.

Rendered Markdown is a representation only: no ordinary create/revise route accepts it as replacement, no renderer writes files/database and no parser is added. TICKET-00028 alone owns explicit validated migration/import and authority switching. Board/Roadmap/next queue belong to TICKET-00027.

Require independent projection-operation, redaction, Planning-view and Markdown-render Permissions. Safe operational Views expose progress/reasons without raw payload, SQL, credentials, paths or unauthorized aggregate data. API/MCP-ready contracts return explicit media type/filename metadata safely but do not implement later Pi transport.
