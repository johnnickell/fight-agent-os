# Explain remaining time through Awaiting review

## Outcome

Humans can inspect an updating, explainable remaining-time range through Awaiting review and compare original
predictions with actual known outcomes. Forecasts remain bounded advice, never a deadline, execution grant or
inferred completion from missing telemetry.

## Scope

- In scope: Bounded forecast policy/computation, attributable immutable prediction basis and outcome comparisons,
  existing protected queries/projections/live integration and independently loaded browser presentation.
- Out of scope: Later Review/QA/publication/PR-handoff horizon, predicting human decisions or merge, model-generated
  guesses, statistical guarantees, automatic grant/limit changes and a general analytics/certification platform.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Update bounded estimate | Owning bounded derived-estimate operation | Current known phase/queue/attempt/limits, safe activity, measured timing and applicable history/defaults | Non-authoritative prediction observation | Retained range or explicit waiting/paused/unavailable state |
| Explain current range | N/A — read-only | Current-authorized prediction identity, basis, confidence and material-change reason | Existing committed projection notification only | Explainable advice, never a transition or external call |
| Compare prediction with outcome | Owning actual-outcome association; comparison is read-only | Original prediction/basis, exact horizon/scope and actual known duration/outcome | Attributed comparison facts only | Inspectable calibration evidence including incomplete/changed cases |
