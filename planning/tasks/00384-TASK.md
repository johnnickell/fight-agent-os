# Retain and safely reuse web evidence

## Outcome

Authorized research can retain useful web evidence privately and later deliver exact historical bytes safely,
including through Artifact references and cached/resumed contexts, without treating prior access or screening as
current permission or silently retrieving the source again.

## Scope

- In scope: Explicit evidence retention through existing Artifact owners, protected web-source/admission lineage,
  bounded screened historical delivery, actual recovery/context integration and failure/availability provenance.
- Out of scope: Another storage/transcript store, general cache or crawler, new evaluator, Planning acceptance,
  duplicate contribution or retention policy, automatic refetch and blanket screening of non-web tool results.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Retain useful web evidence | Existing authorized Artifact admission/verification/reference operation | Exact source representation, sensitivity, provenance and permitted retention | Owning committed Artifact/reference facts | Verified private bytes, not an automatic Planning verdict |
| Inspect original evidence status | N/A — bounded read-only status | Current authorized metadata/availability and historical receipt | N/A | No retrieval or evaluator request, no false fresh observation |
| Deliver historical web content | Explicit authorized bounded screened-delivery operation | Exact permitted Artifact bytes, current policy and admission | Redacted current-validation/delivery observations | Separately authorized Jev evaluation when needed; only admitted content released |
| Continue a supported web-bearing context | Existing original recovery operation with web admission participant | Actual protected lineage, exact covered source and current authority | Owning resumed/held outcome | No stale screening bypass, silent refetch or replayed paid work |
