# Push and reconcile one exact GitHub PR

## Outcome

The original verified instruction commit is pushed without force and represented by one attributable GitHub PR
against the registered default base. Partial provider effects remain inspectable and recoverable without duplicate
publication, Agent credentials or a false claim that the designated checkout has returned safely or the PR merged.

## Scope

- In scope: Protected exact push and PR creation, independent native subject/identity verification, original-effect
  reconciliation, safe PR result and separately attributed read-only provider observations.
- Out of scope: Local commit creation, default return, merge/approval, managed Review/Release Manager, creation of
  a remote repository, source-host enrollment, force push, branch deletion, sync and automatic destructive recovery.
