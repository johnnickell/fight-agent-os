# Forecast remaining work through PR handoff

## Outcome

Extend the existing execution forecast from Awaiting review through verified PR handoff so humans see honest
remaining-time ranges, consumed work and reasons for change without forecasting human merge or granting authority.

## Scope

- In scope: Later Review/revision/QA/recheck/publication/handoff phase measurement and forecast extensions,
  confidence/freshness/basis, known queue/retry/external-operation facts, calibration and existing query/UI delivery.
- Out of scope: A second accounting or telemetry platform, provider quota invention, forecasting human merge,
  model self-report as measurement, guarantees, automatic budget/limit extensions and another Dashboard shell.
