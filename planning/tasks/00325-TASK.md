# Show unmistakable identity and switch through linked continuations

## Outcome

Users can always distinguish the active connection/profile/environment in the terminal and deliberately switch
through a new linked session, preserving prior snapshots, pending history and current authority boundaries.

## Scope

- In scope: Persistent textual identity and unavailable/mutable-mode indicators, theme/light-dark-pair collision
  warnings and explicit preference/accessibility override, safe switch preview and actual linked-continuation
  integration using existing snapshot/session owners.
- Out of scope: New branding, theme/resource catalog, snapshot or session engine, credential lifecycle, in-place
  active-session mutation, provider qualification and overriding current authority with a pinned profile.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect active identity | N/A — presentation/query only | Actual connection/profile/environment, package mode and current readiness | N/A — rendering creates no authority | Persistent legible textual identity, including disconnected/stale states |
| Explain indistinct presentation | Explicit recorded override only when chosen | Enabled connections and exact selected theme/light-dark pairs | Safe preference/override fact at owning profile boundary | Visible collision warning and deliberate accessibility/preference choice |
| Preview a switch | N/A — read-only | Exact old/new configuration, drift, current authority and pending operations | N/A | Concise differences and consequences without changing the active session |
| Continue with new selection | Existing expected-state linked-continuation operation | Current snapshot/session, qualified target, pending history and original outcome | Existing owning continuation/binding facts | New linked session/snapshot; original bytes and lineage remain intact |
