# Enforce shared password acceptance and Argon2id hashing

## Outcome

One reusable password-acceptance boundary enforces the approved Unicode-aware 8–128-character composition policy, rejects known-common passwords through a pinned checksummed license-reviewed local hashed corpus, and produces explicitly configured Argon2id hashes without network access or secret-bearing diagnostics.

## Scope

- In scope: Owned structural password policy; application `CompromisedPasswordChecker` capability; documented normalization/hash/index format; selected local corpus and reproducible transformation; pinned source/version/checksum/license/notices; packaged hashed denylist and integrity verification; deterministic adapter; Argon2id hasher/validator composition and rehash policy; secret-safe validation result mapping; activation/reset/change reusable service; unit/composition/redaction/install tests.
- Out of scope: Activation/reset/change HTTP/UI, runtime breach-network calls, plaintext corpus distribution when avoidable, periodic expiry, password history, administrator password selection, strength meters that transmit input, and changing Fight Access Control package policy.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Validate candidate password | N/A — application policy operation | Inspect Unicode length/categories and local compromised index | N/A — no domain event | Accepted/rejected typed result is returned without retaining candidate material |
| Hash accepted password | Later package authentication operation | Read explicit Argon2id parameters/platform support | Package user events remain package-owned | One salted Argon2id hash is produced and plaintext becomes unreachable after call |
| Verify/rehash password | Later package authentication operation | Verify candidate against stored hash and inspect current parameters | Package authentication event only when operation succeeds | Correct candidate verifies; obsolete parameters request rehash |
| Verify corpus integrity | N/A — startup/install/tooling check | Read pinned manifest/file checksum and format | N/A — no domain event | Missing/corrupt corpus fails closed before password acceptance uses it |

## Validation and permissions

Count 8–128 Unicode characters after rejecting invalid UTF-8; document normalization semantics and avoid transformations that unexpectedly alter user-selected passwords. Require at least one Unicode uppercase letter, lowercase letter, number, and punctuation/symbol category. Spaces and other valid Unicode are allowed but whitespace alone does not satisfy the symbol category. Paste and password-manager input are never blocked. Server policy is authoritative.

Define `CompromisedPasswordChecker` as an application capability with a minimum secret-safe boolean/typed result. The local adapter uses a documented one-way lookup format and deterministic normalization policy appropriate to the corpus. It must not expose corpus entries, candidate hashes, prefixes, indexes, or timing-sensitive diagnostics through public results. No runtime network fallback is allowed.

Pin the corpus source/release, expected checksum, retrieved artifact details, license review, transformation command/version, output checksum/count, and required notice. Keep source/transformed files in the appropriate dependency/data location and verify integrity during clean install/startup or another mandatory pre-use phase. Missing, malformed, or checksum-invalid required data fails closed.

Configure PHP password hashing explicitly for Argon2id with evidence-supported parameters and production startup validation. Use per-password random salts from the platform, `password_verify`-equivalent constant-time behavior, and explicit rehash detection. Never log, stringify, serialize, meter, audit, snapshot, or include candidate/plaintext/hash/lookup material in exceptions. Mark sensitive parameters where supported.

No end-user permission applies. The capability is used only by authorized password-setting operations in later TASKs.
