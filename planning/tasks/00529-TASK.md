# Back up and restore coherent staging state

## Outcome

John can capture, inspect and restore a coherent staging recovery point containing consistent PostgreSQL state,
referenced private files and the required key-version bindings. The actual isolated restoration recovers usable
Planning records and referenced content without reviving stale authority or external effects. A protected Spaces
copy and independent human recovery path survive source-host loss; a timer or upload acknowledgement is not success.

## Scope

- In scope: Consistent staging capture and protected Spaces publication, coherent point inventory/readability,
  bounded scheduling/retention/status, isolated restoration, existing authority/replay/redaction integration,
  independent operator instructions and human Bitwarden kit, measured loss/recovery/capacity/cost evidence.
- Out of scope: Managed-production integration (TASK-00530), another storage/queue/credential/diagnosis engine,
  new backup vendor, runtime vault access, production-data copies, live Planning cutover, automatic activation or
  destructive restore/cleanup, generic disaster-recovery platform or standalone certification work.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Capture a coherent point | Explicit bounded operator/scheduled capture through owning database/storage tools | Exact snapshot boundary, referenced versions, schema/artifact and key dependencies | Safe operational completion/gap receipts, not Domain events | Protected verified point or visible incomplete capture; no business-effect replay |
| Inspect or retain points | Read-only inventory; separately authorized retention operation | Coverage, integrity/readability, age, key availability, holds and cost | Operational disposition receipts only for actual changes | Reads never repair/delete; approved cleanup preserves every retained point's dependencies |
| Recover without the source host | Exact approved isolated restore and existing owner reconciliation/rebuild operations | Selected point/loss/target, independent history and current authority | Existing owner facts for real operations only | Recover usable isolated state with external effects held and originals preserved |
| Prepare independent human access | Human-only kit/custody setup under separate authority | Required versions, access dependencies, independent instructions and bounded resource quote | Secret-free human confirmation of exercised access | Usable recovery path without Fight, failed host or Agent vault privileges |
