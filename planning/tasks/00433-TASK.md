# Edit and recover instruction changes in the Dashboard

## Outcome

An authorized human can edit one recognized instruction file in the existing Dashboard, review its complete diff,
explicitly Save or confirm Delete, and understand conflicts or interrupted outcomes without losing a still-permitted
active draft, silently overwriting work or publishing Git changes.

## Scope

- In scope: Extend the existing viewer with a volatile Markdown form, full change/deletion diff, effective-file
  consequence, production Save/Delete and original-operation status/recovery, authority fences and accessible states.
- Out of scope: Another workspace/editor, arbitrary files, durable manual drafts, autosave/co-editing, AI generation,
  a second Save route, Git publication/sync, automatic merge/retry, checkout substitution and Agent submission.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Draft one file | N/A — volatile human editing | TASK-00431/00430 original content or verified absence and effective-state evidence | N/A | Editable bounded Markdown and complete diff, no mutation |
| Submit reviewed Save | TASK-00432 exact Save changes | Current target/context/base, preview and original operation | Owning verified facts only | One human-authorized local creation/replacement, no publication |
| Confirm Delete | TASK-00432 distinct confirmed Delete | Full deletion diff, tracked/ignored state and remaining-effective-file consequence | Owning verified facts only | Selected-file deletion or truthful refusal |
| Reconcile a conflict | N/A until a new explicit human submission | Currently permitted safe content/diff beside the rejected draft | N/A for inspection | Manual decision without rebase/overwrite or model repair |
| Recover interrupted submission | Read original status; explicit owning reconciliation when permitted | Original intent/outcome/current scope | Existing owner outcomes | Verified result or held uncertainty, never automatic resend |
