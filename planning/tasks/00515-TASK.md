# Synchronize current handoffs during Land publication

## Outcome

Make the shared Land workflow reconcile applicable current Board, Roadmap and README handoffs alongside
parent rollups and generated views before returning control to the human. Maintainers receive a truthful
current action while historical acceptance and delivery checkpoints remain intact. This is the first
independently reviewable slice of [TICKET-00118](../tickets/00118-TICKET.md).

## Scope

- Update the owning Land skill, landing standards and necessary shared handoff guidance to inventory the exact
  subject's current authored handoffs, reconcile their authoritative sources and refresh derived views.
- Distinguish historical acceptance/delivery-pending evidence from current instructions without rewriting
  canonical reports or claiming publication/final-head success before it is verified.
- Require a precise hold for missing evidence, contradictory handoffs or unauthorized changes; preserve
  unrelated routing, requirement ownership and existing review/QA/cleanup gates.
- Verify normal publication and refusal paths directly as part of the same change.
- Out of scope: post-merge recovery (TASK-00516), validator/live-routing implementation (TICKET-00119),
  project-local rollout (TICKET-00120), implementation defect repair, managed database Workflows, automatic
  merge, release/deployment, archive and unrelated cleanup.
