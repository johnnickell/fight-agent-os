# Return the published checkout safely to default

## Outcome

After verified PR creation the designated checkout returns to its registered default branch at the original
verified default revision only when the operation-owned transition is safe. A blocked or uncertain return remains
an explicit partial outcome, protecting unrelated work and retaining ownership instead of claiming completion.

## Scope

- In scope: Admitted exact return transition, real local/result verification and original recovery, shared custody
  disposition, existing effective-context/form-currentness integration and safe post-publication status.
- Out of scope: Push/PR creation, merge, remote/local branch deletion, cleanup platform, fetch/sync, default ref
  movement, automatic compensation, stash/reset/discard, Pi reload or Agent continuation.
