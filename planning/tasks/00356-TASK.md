# Record human Planning answers and operation boundaries

## Outcome

A planner submits or corrects a durable answer to the exact pending question and can distinguish the current
Planning operation from a separately requested successor. This delivers revisioned human decision input for
real database-authoritative Planning without allowing Agent preparation to choose human preferences.

## Scope

- In scope: Human answer/correction submission, exact decision/question revisions, operation intent and transitions,
  pending-choice inspection and recovery integration through existing conversation and Planning owners.
- Out of scope: Another conversation or decision authority, automatic artifact creation/decomposition, guarded
  lifecycle bypass, full browser navigation, persistent unsaved forms or autonomous preference selection.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Answer a question | Explicit answer submission with expected question/decision state | Exact unresolved question and authorized choices/context | Owning accepted-input/decision facts | Durable human answer before dependent delegated work |
| Correct an answer | Explicit semantic correction against the current revision | Prior accepted answer and affected proposal/operation references | Appended correction facts | History retained; dependent stale work cannot use old acceptance |
| Request a distinct operation | Explicit scoped Wayfinder/grill/decomposition intent | Current target, children, lifecycle and allowed next action | Committed owning operation-intent facts | New bounded intent only when separately authorized |

## Validation and permissions

Use TASK-00349's original input/attempt ownership and TASK-00352's authorized attachment/history. Conversation
answers for intake or not-yet-created artifacts are durable input, not fabricated Planning aggregates. When an
answer accepts or corrects an existing Wayfinder DecisionPoint, invoke TASK-00086's semantic operations with its
stable child identity, expected revisions and current Permissions. Keep exact mappings/provenance, not dual writers
of the same decision. New-artifact candidates carry their accepted input into later explicit creation.

Apply TASK-00103 authority enforcement and TASK-00104's verified Fight Agent OS cutover. Semantic Planning changes
use the owning shared transaction and required audit; composing input/decision facts must not introduce nested
transactions or a post-commit gap that reports false acceptance. Ordinary input does not authorize unrelated
Planning mutations. Require current initiating-human scope, exact conversation/question and intent-specific rights;
a model or delegated Agent cannot impersonate the answerer, choose product/priority/boundary/risk preferences or
convert prior input into a new approval. Unknown or conflicting choices stay pending.

Duplicate submissions return the original outcome. Concurrent corrections and replies compare exact revisions;
stale/replaced questions reject rather than silently attaching answers elsewhere. Preserve previous answers and
safe history after conflict, disconnect or process replacement. A correction invalidates affected candidate review
and cannot overwrite another human edit. Accepted input never renews expired/revoked/consumed authority.

Keep Wayfinder resolution, grill, to-tickets and to-tasks distinct. A Wayfinder interview does not produce an EPIC;
a separately invoked grill prepares one EPIC. Creation never starts decomposition or execution. Inspect current
children before proposing additions/revisions. Terminal/archived targets require their existing reopen/restore
operation; never call those implicitly. AFK factual preparation stops at a genuine human choice. Progress exposes
known required/settled decision units and unresolved state, not token/time percentages.
