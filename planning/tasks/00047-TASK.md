# Deliver rotating refresh and current-session logout

## Outcome

Protected versioned refresh and logout operations use only the scoped opaque cookie and `AuthenticationService` to rotate bounded authority, expose one safe conflict outcome, revoke replayed or non-authoritative sessions, revoke only the current session on logout, and clear cookies/client memory on terminal outcomes.

## Scope

- In scope: Refresh/logout routes and single-use-case Actions; cookie extraction only; CSRF/Origin/Fetch/JSON/HTTPS/rate controls; `AuthenticationService::refresh()`/`logout()` integration; `RefreshResult` rotated/conflict/terminal mapping; access response and cookie rotation; cookie expiration; client feature services and single-tab state transitions; current-session logout UI/action; OpenAPI; PostgreSQL conflict/reuse/revocation/race and HTTP/cookie/redaction tests.
- Out of scope: Multi-tab Web Locks/BroadcastChannel, session listing/other-session revocation, logout everywhere, `/api/v1/me`, credentials in request JSON, broad account UI, token persistence, and changing package refresh/reuse policy.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Rotate refresh authority | `AuthenticationService::refresh(cookie credential)` | Resolve current/used credential, authoritative session/user/version and limits | Package refresh lifecycle outcome | One valid rotation stores used digest/new credential, advances idle within absolute, returns memory access token and replacement cookie |
| Report bounded conflict | Same service call | Resolve most recently used credential within conflict window | N/A — typed `RefreshResult::conflict` | Safe retry signal is returned without credential/session detail or immediate family revocation |
| Reject replay/terminal session | Same service call | Resolve used credential outside conflict or non-authoritative state | Package revocation/failure outcome | Session is revoked or fails closed; cookie and client memory are cleared |
| Logout current session | `AuthenticationService::logout(cookie credential)` | Resolve session selected by current credential | `CurrentSessionLoggedOut` | Only selected refresh session is revoked; cookie/access memory clear |

## Validation and permissions

Read refresh credential only from TASK-00045's exact cookie; reject/ignore body/header/query/form alternatives according to accepted profile and never make it JavaScript-readable. Apply CSRF, exact Origin, Fetch Metadata, HTTPS, approved JSON body shape, and endpoint rate limits before service invocation. Refresh/logout authority is possession of protected cookie plus request controls; no role/permission applies.

Use package `AuthenticationService::refresh()` directly. On rotation, proposed idle expiry is min(now plus ordinary/remembered idle, original absolute expiry); absolute expiry and remembered flag never change. Replace cookie with new opaque credential and persistence matching session type, return new fifteen-minute access token only through explicit View/memory seam, and invalidate the superseded client generation.

Map package conflict to one explicit safe recoverable response consumed by TASK-00048; do not retry in the server Action or loop. A previously used credential outside accepted conflict behavior, revoked/expired/non-active/wrong-owner/stale-auth-version state is terminal and cannot issue tokens. Preserve package compromise revocation semantics.

Logout invokes package service for the presented current credential only. Regardless of unknown/already-terminal server credential, client-facing terminal handling must expire the cookie and clear in-memory authority without claiming a revocation that did not occur. Choose/idempotently map response per ADR and avoid existence disclosure. It cannot revoke every session.

All known failures use sanitized correlated mapping. Never expose/log cookie/credential/digest, access token except intentional response, user/session existence detail, provider/internal exception, SQL, or stack trace. OpenAPI distinguishes HttpOnly cookie input from Bearer output.
