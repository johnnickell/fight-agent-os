# Emit useful native diagnostics without disrupting operations

## Outcome

Application operators receive useful native Monolog records across all included channels and levels, while a
producer/formatter/handler failure preserves the original operation outcome and exposes bounded independent
observability degradation. This is approved slice A of [TICKET-00111](../tickets/00111-TICKET.md), not collector,
search or archive delivery.

## Scope

- In scope: Actual application logger output replacing ordinary null/threshold suppression; native JSON/Throwable
  formatting, contextual processor metadata, failure isolation and non-recursive independent status integration;
  review of producers activated by restoring ordinary output; producer-to-capture encoding qualification.
- Out of scope: Collector/queue implementation, Loki/archives/browser, new audit authority, SQL statement logging,
  pipeline redaction, unrestricted dumps, transcripts, backend credentials, dependency updates and service enrollment.

Consume [WF-037's diagnostic contract](../wayfinder/tickets/WF-037-define-redacted-diagnostics-and-shared-http-adoption.md#diagnostic-contract)
and [WF-038](../wayfinder/tickets/WF-038-define-log-collection-and-failure-recovery.md). Use all eight native Monolog
levels, including DEBUG, without ordinary sampling, channel gaps or a success-shaped null fallback. Keep native
message/context/extra/channel/level meaning and useful emitted exception class/message/code/file/line/trace/chained
causes. Enable native JSON traces; retain native normalization defaults/limit markers, not an invented lossless
object serializer or arbitrary trace/message cap. Format-boundary escaping is not content redaction.

Add trusted available service/release/process/operation relationships without inventing missing lineage; provide
bounded context lifetimes for the HTTP, bus and worker consumers in TASK-00452–00454. Producer secret avoidance
precedes emission: review activated cache/process/scheduler and other real logger callers, including command-line
and provider material. Do not fix unsafe producer content by sink filtering, disable its channel or silently amend
package contracts. A demonstrated upstream capability conflict returns to its owner before dependent activation.

Isolate context projection, normalization and handler failures without repeating business work, replacing its
original exception/result or weakening required audit/evidence. A local logger return is not a capture, query or
archive receipt. The independent failure signal contains only bounded component/stage/time/known uncertainty;
never the failed raw payload, recursive logs or an unbounded secondary spool. Shared process/memory/disk failures
may still defeat operation: report limits rather than promise arbitrary fault survival.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Emit application diagnostics | Existing producer operation; no new business command | Actual available safe context | Native log observation, not a Domain/Workflow event | Structured diagnostic reaches the qualified local output boundary |
| Explain an emitted exception | Existing owner reports its failure | Native Throwable normalization without arguments/locals | Diagnostic observation | Useful exact emitted text and native trace/cause fields remain private |
| Preserve operation during diagnostic failure | Guard diagnostic work only; never rerun business work | Independent failure-path availability/known uncertainty | Bounded degradation signal, not successful delivery | Original operation outcome remains; missing diagnostics are not silently called healthy |

## Validation and permissions

No browser or installation permission is added. Producer metadata is not authority; accept only actual trusted
relationships and preserve client correlation provenance under its existing validator. Avoid deliberate emission
of secrets, credentials, unrestricted request/response/object content, stack arguments or locals. Already emitted
content is not pipeline-redacted. Existing mandatory credential/audit/evidence rules remain binding.

Follow [ADR 0001](../adr/0001-application-ownership-and-orchestration.md) and
[ADR 0002](../adr/0002-postgresql-consistency-and-durable-effects.md): logging is observational, not another transaction,
commit witness or synchronous remote delivery participant. Reuse Monolog/Common contracts and injected dependencies;
no speculative telemetry framework or source-package/vendor edits.

## Acceptance criteria

- [ ] Every included actual application logger/channel emits all eight native levels; no general NullHandler,
  ordinary threshold, sampling or alternate sink silently drops accepted records.
- [ ] Native record/context/extra and emitted exception/cause/trace fields survive the qualified output encoding;
  native depth/item markers and unavailable metadata remain explicit, not silent whole-record truncation.
- [ ] Activated real producers avoid deliberate secret emission without collector redaction or blanket suppression.
- [ ] Diagnostic construction/format/handler faults preserve the original success/rejection/exception and required
  audit semantics, never recurse or repeat business work, and produce bounded independent degraded/unknown status.
- [ ] Actual malformed/non-UTF-8/large records compose with the selected capture/framing contract, with exact emitted
  byte preservation or explicit loss/uncertainty. Local output is never labelled indexing or archival success.
- [ ] Owned behavior/integration evidence, direct output/status qualification and full `./bin/build` pass.

## Verification and evidence

Test owned diagnostic isolation/context/output behavior with actual Monolog and controlled faulting collaborators,
not Monolog internals or configuration text. Use actual level codes, chained exceptions, normalization-limit markers,
malformed/large values and safe secret-negative producer fixtures. Compare business outcomes before/after diagnostic
faults and test independent status failure without recursion. Directly inspect the configured output using owning
tools; downstream collection evidence must come from the qualified supplier, not a fake sink.

Run repository `./bin/*` focused checks and `./bin/build`; record exact dependencies, scope, counts, warnings and
unverified fault boundaries. A confirmed bug discovered during implementation needs a failing regression before
repair. Runtime experiments require separately bounded targets/effects; planning approval starts no service.
