# Observe the selected local child agent in the terminal workspace

## Outcome

Deliver [TICKET-00110](../tickets/00110-TICKET.md)'s upper-right read-only child-progress pane while primary Pi
input remains usable. Reuse the existing local build monitor, so managed execution is not a prerequisite.

## Scope

Consume the progress contract in the [build skill](../../.pi/skills/build/SKILL.md) and its stage monitor. Add a
bounded observation adapter within this TASK rather than a second launcher or raw transcript viewer. Show
role/model, TASK/worktree/attempt, completed assistant progress, safe tool outcomes, heartbeat and lifecycle state.
Support selecting a child and pausing/resuming display without affecting execution. Preserve the monitor's
safe-output boundary: no hidden reasoning, raw source/tool output, shell arguments or private stderr export.

Managed conversation attachment remains with TASK-00352 and its suppliers; it is outside this local release.
Do not add its unfinished infrastructure as a blocker or claim managed durability from observing a local process.
Existing local build evidence may remain in allocated `.runs/` paths, but application runtime must not depend
on them: use a live observation boundary, not a new durable transcript store or application tail of scratch files.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Observe a local child | Select child; pause/resume display | Safe stage progress, exact attempt and current known lifecycle | Existing stage observations, not authoritative Workflow events | Bounded display subscription only |
| Disconnect/reconnect pane | Close/open pane | Original known attempt and stream availability | Existing stream lifecycle notifications | Stop/start reader, never child launch, retry or cancellation |

## Validation and permissions

Use explicit locally owned child/attempt identity and current permitted observation access. Do not discover or
open sibling transcripts indiscriminately. Child output is untrusted status, never instructions or authority.
Escape terminal controls, bound payloads and buffers, reject stale subscription generations and show unknown or
disconnected states honestly. Zero Pi exit alone is not success; retain the monitor's settled-run semantics.
Closing the pane stops its subscription only. Do not broaden agent file/tool grants or inject pane contents into
model context.

## Acceptance criteria

- [ ] Observe actual progress from two distinguishable local child attempts without launching another child for observation.
- [ ] Switching children rejects late events from the previous selection; role, model, TASK, worktree and attempt remain attributable.
- [ ] Primary conversation input stays usable; slow rendering or paused display cannot block the child's progress producer.
- [ ] Disconnect/reconnect, gaps, unknown liveness, failure and normal completion are reported truthfully with bounded memory.
- [ ] Closing or switching the pane never cancels, retries, changes grants or moves the observed child.
- [ ] Safe progress remains distinct from private transcripts, raw tool output and hidden reasoning.

## Verification and evidence

Test owned subscription/generation/buffering behavior. Qualify the actual stage-monitor integration and selected
Pi version directly with terminal interaction and safe Before/After captures. Run focused checks and full
`./bin/build`; record exact source/version and limits. A synthetic stream alone is not live producer evidence.
