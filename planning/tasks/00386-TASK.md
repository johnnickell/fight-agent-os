# Capture and inspect sanitized phase activity

## Outcome

Operators can inspect useful safe metadata from actual phase/tool execution, clearly distinct from authoritative
Workflow decisions and protected model conversations. Missing or reordered observations remain honest gaps rather
than becoming a prerequisite for execution recovery.

## Scope

- In scope: Selected real producer integration, bounded sanitized observation ledger, stable identity deduplication,
  phase/Agent parentage, protected evidence references and bounded application/API/console activity inspection.
- Out of scope: Another execution engine, global observation sequence/spool, raw payload collection, transcript or
  excerpt search, general telemetry platform, usage aggregation, Dashboard components and observation-driven recovery.

| Use case | Commands | Queries | Events | Expected side effects |

| Capture safe operational fact | Admit selected typed sanitized observation | Actual producer, Workflow/phase/process and applicable scope | Non-authoritative observation fact | Bounded ledger write, never Workflow advancement |
| Inspect selected phase | N/A — read-only | Current-authorized phase/Agent parentage and bounded safe activity | N/A | Distinct observed facts with honest gaps and timestamps |
| Follow evidence reference | N/A — use existing protected read | Exact permitted subject/Artifact and current availability | N/A | Safe metadata or authorized bounded bytes through existing owner |
