# Register and link the exact generated checkout

## Outcome

An admitted creation stage registers exactly the generated local Git repository, establishes its owned physical
link and designation, and reconciles original outcomes after interruption without duplicate identities, marker
overwrite or adoption by name/path similarity. Earlier local and optional remote effects survive failure.

## Scope

- In scope: Creation-stage composition of existing registration/link/designation owners, exact verified evidence,
  confirmation binding, original-outcome recovery and protected partial-result inspection.
- Out of scope: New identity/matching engine, arbitrary existing-content adoption, Git generation/publication,
  context/mode initialization, cleanup, final receipt and automatic Planning/Agent startup.
