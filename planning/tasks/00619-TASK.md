# Run and reuse selected verification passes locally

## Outcome

Let local Fight stages run only affected checks and reuse valid evidence without mistaking a skipped check for a successful run.

## Scope

Use the shared selector and all four local entry points, including frontend-owned browser smoke. Give each pass its own input fingerprint and success receipt, covering relevant source, tests, shared inputs, configuration, locked dependencies, tool identity, and required artifacts. Keep an explicit full run and a way to force fresh execution. Integrate with local verification across Work, Review, QA, and Land without changing role authority or independent judgments. Do not add hosted result reuse.

## Acceptance criteria

- [ ] Demonstrate ran, reused, and not affected as distinct outcomes. Planning-only work does not provision application or Harness dependencies.
- [ ] Relevant input changes and missing or invalid artifacts invalidate the corresponding reuse. Unrelated inputs do not invalidate a valid receipt. Missing, failed, interrupted, or unverifiable evidence never passes as a hit.
- [ ] An explicit full run and a forced fresh pass work. Reused evidence does not become independent acceptance or bypass stage obligations.

## Verification and evidence

Record exact commands, affected and unaffected examples, cold and focused local timings, and receipt failure and reuse evidence. Verify using owning commands and bounded probes; surface warnings and incomplete evidence. Hand off to independent Review and applicable QA.

## Coordination

Needs the selector and the four usable local entry points, including smoke. May proceed in parallel with [TASK-00620](00620-TASK.md). Planning approval does not select a checkout or authorize implementation or publication.
