# Retain immutable Harness snapshot bindings

## Outcome

An authorized session owner retains one coherent immutable Harness snapshot and exact binding facts beside the
Repository snapshot, with inspectable history and recoverable original outcomes. Persisting those facts never
launches an Agent or creates a grant.

## Scope

- In scope: Exact snapshot retention/binding operation, authorized history inspection, expected-state/idempotency
  contracts, current reference/selection fences and atomic required audit through PostgreSQL.
- Out of scope: Another session/transcript or grant engine, resource history duplication, credential store,
  active-snapshot replacement, runtime activation, provider calls and final role-session integration.
