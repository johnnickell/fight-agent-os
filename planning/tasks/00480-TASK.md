# Export selected requester-owned restored diagnostics

## Outcome

The owner of a currently valid temporary archive-search scope explicitly exports selected restored diagnostic
records through native Logs, without renewing the scope or bypassing current authority. This approved slice C of
[TICKET-00116](../tickets/00116-TICKET.md) extends the real export journey into verified restored search; it is not
another restore job, query engine or extraction permission.

## Scope

- In scope: Native restored selection/export controls, current requester/readiness/expiry checks throughout source
  fetch and output, restored query integration with the existing export path, truthful coverage/completion and actual
  browser/state/restriction participation.
- Out of scope: Scope sharing/administration, lifetime renewal, automatic restore or extraction replay, live-tail
  mixing, archive download, new spool/copy store, permanent report or provider provisioning.

Reuse [TASK-00478](00478-TASK.md)'s exact-record export/output/integrity/admission behavior,
[TASK-00474](00474-TASK.md)'s current scope authority, [TASK-00475](00475-TASK.md)'s actual verified temporary content
and [TASK-00476](00476-TASK.md)'s native restored query integration. Export the explicit selected server-side scope,
not rendered previews. Preserve original bytes/IDs/clocks/source/fragment provenance, tied observations and legitimate
duplicates. Unknown fields remain unknown; malformed/binary/large content is reversible and never silently redacted.

Require current `READ_LOGS` + `EXPORT_LOGS` + `RESTORE_LOG_ARCHIVES`, requester ownership, ready or deliberately
published verified-partial content, unexpired fixed lifetime and current disclosure policy before fetch and private
release and every bounded output batch. Another Super Admin's read/export powers do not grant this requester's scope.
Unknown authority denies. Readiness/expiry captured at submission or in a request principal cannot authorize the later
batch. Failed/cancelled/expired scopes are inaccessible even while physical cleanup is delayed. Backend disappearance
is not successful empty output, and export never renews source leases or the fixed 24-hour ready lifetime.

Retain <=7 days/16 MiB total encoded output/30 seconds, <=16-KiB requests with <=4-KiB literal search, <=64-KiB output
batches and <=1-MiB queued output. Use the same two installation-wide shared live/restored read/export/download slots
and one/requester; no separate restored pool or hidden fanout. Count abandoned work until cancellation/completion is
confirmed. Browser/proxy/worker/provider resources remain within the qualified common transfer envelope.

Declare the selection, time basis, verified subset and known gaps truthfully; distinguish complete traversal of an
explicit subset from completeness of the original incident or archive selection. Actual limit/deadline/expiry/purge/
backend interruption must not emit false complete/integrity confirmation. HTTP success or EOF alone is insufficient.
Use TASK-00478's bounded completion mechanism and output checks, without treating emitted diagnostics/downloads as
Workflow evidence or replaying original business work.

Join the early owner/output restriction fences before exposure. Actual restored export buffers/caches and late
completion participate; a future all-copy purge TASK does not excuse stale release. Keep already released/in-flight
bytes and operator copies explicitly outside recall guarantees. Clearing the browser is not proof of remote erasure.

Integrate accessible permission-gated controls with the existing restored view. On refresh/logout/expiry/identity/
scope change, retire transfer/private state, reject late successes and errors, and show permitted truthful status.
No automatic retry after credential restoration, scope re-creation or selection widening. Bound keyboard/focus/status
announcements and retain clear limits/partial results across narrow/zoom/light-dark/reduced-motion presentation.

## Validation and permissions

Follow ADRs [0001](../adr/0001-application-ownership-and-orchestration.md),
[0003](../adr/0003-browser-authentication-security-profile.md) and
[0004](../adr/0004-client-authority-and-runtime-state.md). Use exact current capabilities, same-origin Bearer/applicable
CSRF, no-store, safe filename/media type, inert rendering and volatile generation fences. Scope IDs/cursors and client
visibility never confer authority. No caller tenant/LogQL/path, Role shortcut or storage/hold/purge privilege. Denied
references disclose no hidden existence/counts. Keep private content/selections/tokens out of URLs/history/referrers/
telemetry/logged payloads; retain existing public HTTP safety and separate evidence-download authority.

## Acceptance criteria

- [ ] Actual native restored export uses verified older archives and exact selected content through the real common
  export path; tied/malformed/large data and verified partial coverage preserve fidelity and honest completeness.
- [ ] Missing any required permission, another requester, unready/failed/expired scopes or unknown policy denies;
  current authority/readiness/expiry/purge races stop further release even with delayed physical cleanup.
- [ ] Export cannot renew scope life, restore automatically, replay business/extraction work or silently substitute
  live data; expired/interrupted provider work never yields a complete export or premature admission release.
- [ ] Shared transfer/byte/time/batch/browser budgets, explicit integrity/completion, no-store and late-result
  fences hold under concurrent live/download work, slow clients, cancellation and credential restoration.
- [ ] Owned API/application/client/scope-race tests, actual accessible browser and provider evidence, relevant direct
  resource qualification and full `./bin/build` pass; inherited live-export evidence is labelled, not called fresh.

## Verification and evidence

Use actual admitted/restored safe archives with old original clocks, tied records, binary/large fragments and an
explicit verified-partial subset. Exercise two requesters, independent permission combinations, capability/session/
purge changes and fixed expiry during output with real authoritative storage. Measure shared admission and buffers
with live export/download competition; test missing backend, slow/disconnected clients, false/absent completion,
refresh and late UI results. Inspect actual browser state and keyboard/focus/responsive behavior. Qualify transport/
resource changes directly, never with product tests of configuration, migrations, wrappers or vendor internals.
Run focused repository wrappers and full `./bin/build`, recording exact new versus inherited evidence and warnings.
No live transfer, new runtime experiment or actual restore is authorized by this record.
