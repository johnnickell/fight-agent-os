# Browse complete Planning hierarchy and history

## Outcome

Authorized users can progressively browse every database-authoritative Planning artifact, hierarchy, revision history, criteria/evidence, dependency effect, progress, archive and rendered representation inside the selected Repository without loading the whole portfolio or revealing hidden records.

## Scope

- In scope: Repository Planning routes/navigation; type-aware hierarchy/tree/list and detail pages for WayfinderMap, WayfinderTicket, ResearchNote, Prototype, Epic, Ticket, Task and standalone Task; parent/child links; typed current content/use cases/decisions/criteria/evidence/delivery links; direct/transitive dependencies; lifecycle/archive/closeout readiness/progress; paginated history/provenance; current/archive modes; read-only rendered Markdown view/download; filters/pagination/URL state; permission-aware partial Views; API services/mappers; responsive production components/catalog/state evidence.
- Out of scope: Editing/mutations, browser conversations/proposals, event payload/SQL display, arbitrary graph visualization, source Markdown authority, fake progress, full-portfolio eager loading, provider polling, Roadmap/queue UI and migration operation.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Browse hierarchy | N/A — read-only interaction | Repository hierarchy/list with bounded type/status/archive filters | N/A — reads emit no event | Navigable typed summaries load progressively under current scope/revisions |
| Inspect artifact | N/A — read-only interaction | Get type-specific current detail, parent/children, criteria/evidence and relationships | N/A — reads emit no event | Complete safe current View displays without treating projection as authority |
| Inspect history/impact | N/A — read-only interaction | Paginated semantic history/provenance and direct/transitive dependency impact | N/A — reads emit no event | User can explain current state while hidden nodes remain safely summarized |
| Browse archive | N/A — read-only interaction | Independently paginated archived list/detail under explicit mode | N/A — reads emit no event | Archived work remains discoverable without appearing active or implying deletion |
| View rendered Markdown | N/A — representation query | Render typed current View at revision/template version | N/A — render emits no event | Read-only labeled Markdown displays/downloads without source mutation/input |

## Validation and permissions

Use typed TICKET-00026/27/28 API Views and links; never parse source Markdown or raw events in React. Route identifiers are stable safe references under TASK-00107's selected Repository. Verify each response subject/scope/revision before cache insertion/render. Cache/list pagination keys include principal, Workspace, Repository, type/filter/archive/cursor and relevant revision; Repository switches cannot reuse stale data.

Render type-specific sections and relationship semantics rather than one generic document page. Show machine lifecycle plus centralized labels, archive separately, and closeout/eligibility as derived reasons. Progress uses authoritative known child/decision/criterion counts and explains denominator change; no turn/token/time percentages. TASK Done remains distinct from review/PR/merge/delivery observations.

History is semantic, paginated and provenance-safe; do not expose raw event payload/storage, internal IDs unnecessarily or emergency-redacted content. Evidence and links show bounded typed metadata, availability/supersession and permission. Dependency impact is bounded; inaccessible nodes use safe redacted explanation without enabling enumeration. Partial query state identifies omitted/unavailable sections rather than presenting completeness.

Current and archive are explicit URL/filter modes and separate pagination. Archive does not imply Won't Fix/completion/deletion. Rendered Markdown is labeled with database authority, aggregate/view revision and template version, safely escaped/presented, never editable/submittable and never synchronized to Git.

Require distinct Planning/detail/history/evidence/archive/render Permissions as APIs define. Unknown/stale principal or Repository fails closed. Provide loading/skeleton, empty, denied, not-found, archived-parent, stale revision, partial section, redacted dependency, unavailable service, offline read-only and retry states with accessible announcements/focus behavior.
