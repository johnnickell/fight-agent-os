# Add the local QA skill and behavioral evidence handoff

## Outcome

John can invoke a local `qa` skill against a reviewed TASK or an open PR, exercise its actual browser or terminal
behavior, and receive a durable PASS, FAIL, INCOMPLETE or justified N/A report. Implementation consumes confirmed
QA failures; landing consumes current QA evidence and publishes suitable captures before human merge.

## Scope

- In scope: Pi skill, canonical QA report and run artifacts, runtime/subject checks, browser and terminal evidence,
  TASK/PR intake, focused reruns, work/review/next/land integration, local qualification and inventory updates.
- Out of scope: Managed Agent provisioning or PHP Workflow phases, production/test-code changes, screenshot
  uploader infrastructure, installing browser/terminal tools globally, automatic repair or merge, and relaxing
  review, publication, privacy or sandbox requirements.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| QA a reviewed TASK | `/skill:qa TASK-NNNNN` | TASK, review, exact source/runtime, acceptance scenarios | N/A — local skill | Owned test interactions and ignored report/captures |
| QA an open PR | `/skill:qa <PR URL>` | PR base/head, TASK, review, runtime provenance | N/A | Local evidence for the current PR revision; no implicit PR write |
| Repair a confirmed failure | Existing `work` invocation | Canonical QA findings and current subject | N/A | Existing authorized regression/repair/review flow |
| Publish QA evidence | Existing authorized `land` invocation | Current QA and artifact audience/accessibility | N/A | PR evidence under existing publication authority |

## Validation and permissions

Use an independent QA session and exact reviewed subject. QA may exercise only owned isolated test services and
disposable data within the request; it cannot edit implementation/tests or fabricate captures. Missing tools or
unproven runtime identity remain incomplete. Secrets and private user data do not enter public evidence.
Publication and implementation are separate operations; the skill does not enforce a hosted merge gate.
