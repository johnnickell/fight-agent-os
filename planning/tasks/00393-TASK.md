# Drill into sanitized phase activity

## Outcome

Humans can inspect selected phase/Agent activity below the primary Summary, distinguishing authoritative Workflow
decisions from optional observations without exposing any conversation transcript or message excerpt.

## Scope

- In scope: Independent Activity section, phase/Agent timelines, bounded safe metadata search/cursor windows,
  selected-phase drill-down, authorized evidence links and explicit observation gaps/freshness.
- Out of scope: New observation ledger/search service, transcript viewer, raw output collection, execution/recovery
  decisions, embedded overview timelines and fabricated later Review phases or verdicts.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect phase timeline | N/A — read-only | Existing exact phase/Agent parentage and semantic history | Existing committed live updates only | Bounded discoverable phase detail, never authority |
| Search activity window | N/A — read-only | Existing safe metadata query with scoped stable cursors | N/A | Sanitized activity with honest gaps and independent states |
| Follow safe evidence | N/A — existing protected read | Current-authorized exact evidence reference | N/A | Safe link/bytes through evidence owner, no implicit execution |

## Validation and permissions

Consume TASK-00391's detail/authority/live composition and TASK-00387/00386's actual phase/activity queries
transitively. Reuse the same source projections, safe field policy and lifecycle restrictions; no browser ingestion
of raw Pi JSONL, assistant/model responses, prompts, compiled instructions, thinking, signatures or excerpts.
Conversation lifecycle metadata may be shown only when authorized; Planning conversations remain linked under Planning.

Validate exact Workflow/PhaseAttempt/ProcessAttempt/Agent parentage and bounded filters/cursors. Show known safe
capability, intent/target summary, available producer/receipt times, outcome/exit/failure class and permitted evidence
references. Unknown or omitted fields stay unknown; raw arguments, commands, paths, environment and tool output
are not intrinsically safe. Large safe output belongs behind existing protected Artifacts, not inline unbounded logs.
Search excludes message bodies, raw logs and Artifact contents.

Make authoritative transitions and optional observations structurally distinct, not merely different colors. Missing,
delayed, repeated, reordered or purged observations do not prove no tool ran, completion, zero usage or a recoverable
process. Preserve exact identities, source/projection freshness and partial timing instead of inventing a global
order or duration from receipt times. Dense activity belongs below Summary, not inside compact overview rows.

Render bounded windows without silently capping accessible history; explain cursor expiry and explicit restart.
Preserve stable selection and result semantics through live refresh. Scope/authority/restriction changes retire
pending loads and private data; old errors/successes cannot replace a new selection. Loading/empty/denied/stale/
partial/interrupted/cancelled/failed/purged/unavailable states are section-local, never a Workflow transition or
an excuse to erase the dossier. Viewing or retrying a read never triggers provider calls, capture or recovery.
