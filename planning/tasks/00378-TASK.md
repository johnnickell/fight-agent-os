# Inspect and retrieve protected evidence

## Outcome

Authorized terminal/API consumers can inspect exact evidence subjects and check receipts, discover every changed
file and retrieve bounded private content without public storage access or confusing live observations with retained
immutable evidence. TICKET-00097 later renders these same capabilities in the browser.

## Scope

- In scope: Shared application queries, protected API/console delivery, stable manifest pagination, lazy file-body
  reads, bounded safe previews/downloads, sensitivity/current-access checks and explicit availability outcomes.
- Out of scope: Browser components, Review/acceptance, arbitrary file browsing, public/presigned storage bypass,
  transcript search, automatic storage repair and new evidence capture from a read operation.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect retained evidence | N/A | Exact subject, contribution/check metadata and Artifact state | N/A | Permission-filtered bounded result, no certification or repair |
| Discover changes | N/A | Stable scoped cursor over complete changed-file manifest | N/A | Every authorized file discoverable without loading all bodies |
| Read private content | N/A | Exact verified Artifact/file bounded preview or download | N/A | Authorized private stream or denied/restricted/purged/corrupt/unavailable result |

## Validation and permissions

Consume TASK-00377 and its exact subject/provenance/storage suppliers plus TASK-00117's protected transport. Direct,
console and HTTP entry paths enforce current Repository/Workflow/assignment and sensitivity access before metadata
or byte disclosure; a URL, ID, template or cached projection is never authority. Do not leak existence, private
locators, unrelated source or raw provider errors on denial. Reads never mutate evidence or start a check/upload.

Return complete bounded manifests through stable deterministic scoped cursors, with closed filter/size/time limits.
Bind cursor and file requests to exact subject/revision and current authority; stale/cross-scope tokens deny safely.
Show explicit binary, oversized, missing, purged, restricted, corrupt and unavailable states rather than silently
omitting files or returning replacement live bytes. Keep mutable worktree observations separately labelled and never
use them as fallback for unavailable retained base/head evidence.

Validate actual media type and safe display/download names without trusting extensions. Render previews inert and
allow only supported safe representations; never execute HTML/SVG/scripts or archive/file paths as active content.
Bound parsing, ranges, decompression, stream duration/concurrency and response size. Downloads pass through the
current-authorized application boundary; no arbitrary bucket/key, public object URL or permanent bearer link.

Check current lifecycle/redaction generation and visibility at disclosure, fencing late asynchronous reads against
revocation or quarantine under the supported streaming contract. Apply no-store/private-response protections and
sanitized errors; browser consumers inherit ADR 0004's volatile context fences, not persistent business caches.
Explain limits for already delivered bytes; do not claim instant recall. TASK-00380 consumes these denial/invalidation
participants for cross-copy redaction. Unsupported preview formats remain safely downloadable only when permitted.

## Acceptance criteria

- [ ] Authorized consumers inspect exact subject/check/provenance facts and discover all manifest entries through
  stable bounded pagination; current denial or cross-scope cursors expose no private metadata/bytes.
- [ ] Safe previews/downloads reject active-content, path/key and resource-exhaustion inputs without public storage
  or credential exposure; binary/oversized/restricted/unavailable states are honest.
- [ ] Revocation/redaction and late-result races cannot revive retired access; private responses are not opted into
  persistent caches and retained evidence is never replaced by a mutable worktree read.
- [ ] Queries produce no acceptance, capture, repair, provider call or business-state transition.

qualification stays with TICKET-00097, not a demonstration screen here. Run focused checks and `./bin/build`; retain
bounded private test evidence, warnings and unsupported preview limits under `.runs/`.
