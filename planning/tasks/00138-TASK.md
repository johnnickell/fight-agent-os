# Define and qualify the terminal execution sandbox boundary

## Outcome

Produce the human-readable PHP ownership and sandbox contract, then directly evaluate local container and VM primitives against it. Record failures and unsupported requirements as blockers, never as sandbox readiness.

## Scope

Deliver the terminal-first slice of [TICKET-00032](../tickets/00032-TICKET.md). Preserve its security, PHP ownership,
durability and fail-closed contracts. Browser presentation, database Planning cutover, review/QA/publication,
release and deployment are outside this TASK. An unresolved required sandbox property blocks live Agent launch.
John's 2026-09-27 amendment permits Engineer sudo/root and private Docker-engine access inside a dedicated
mountless VM, treating the entire guest as Engineer-controlled. Qualification targets the external VM boundary,
not guest user/container restrictions. Host/sibling isolation, private Git, external broker/credentials and limits,
separate Team Lead/reviewer boundaries and independent validation of worker check results remain mandatory.
