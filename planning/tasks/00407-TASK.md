# Materialize pinned source into one owned destination

## Outcome

One admitted creation stage materializes exact pinned source with only declared deterministic transformations into
a new owned destination. Interrupted writes remain attributable and reconcilable without overwriting unrelated work
or creating another attempt/directory to hide uncertainty.

## Scope

- In scope: Actual local generation adapter, exact transformation enforcement, destination/resource fencing,
  original-effect ownership/reconciliation and bounded stage receipts through the creation-attempt owner.
- Out of scope: New attempt state machine, catalog policy/schema, source fetching, Git initialization, preparation,
  root installation, sandbox platform, existing-content adoption, automatic cleanup and browser orchestration.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Materialize admitted source | Execute exact committed generation-stage intent | Current authority, pinned inputs and destination ownership | Verified stage facts recorded through attempt owner | New owned files with exact declared transformations |
| Reconcile interruption | Explicit original-effect reconciliation; repeat only proved-safe missing work | Actual original resources, content/ownership and prior outcome | Verified original result or hold | Preserve partial state without duplicate destination or blind extraction |
| Inspect local result | N/A — read-only | Safe exact manifest/input/output evidence and retained resources | N/A | Bounded truthful stage facts, not overall creation completion |
