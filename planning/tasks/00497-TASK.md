# Restore optional-Jev workspace startup and child QA instruction reads

## Outcome

Jev is intentionally unconfigured, and explicit mandatory-instruction reads fail to establish their linked
references. This supports TASK-00447 and the consuming CMS qualification without waiving their remaining QA.

## Scope

- Separate Harness access health from optional evaluator readiness; permit genuine not-enrolled startup and
  enrolled access with unavailable optional screening, while holding missing, malformed or failed authority.
- Make explicit instruction reads use the same bounded, witness-checked reference chain as ordinary reads.
- Clarify ordinary canonical report/probe reads and preserve strict explicit receipt/evidence validation.
- Exclude enrollment changes, credentials, command gating, source-project repairs, and fabricated active status.
