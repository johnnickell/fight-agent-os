# Find and follow Workflows in the sessions Dashboard

## Outcome

Humans can find real repository-scoped Workflows, follow committed updates, change visibility safely and open a
useful Summary dossier without transcript-heavy cards or fabricated metrics. The production Dashboard extends the
existing honest destination, frame and theme rather than creating another shell or authority store.

## Scope

- In scope: Repository-scoped compact table, whole-result search, stable pagination, overview summaries, Archive/
  Restore controls, Summary detail and independently loaded section boundaries, production live transport integration.
- Out of scope: Changes/Evidence bodies and Activity presentation owned by TASK-00392/00393, intervention and Start
  integration owned by TASK-00394/00395, new projections/accounting/forecast policy, new shell/theme or fake records.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Find current or archived work | N/A — navigation/search is read-only | Existing whole-result search, stable cursors and scoped summaries | Existing committed projection notifications only | Safe bounded view, never execution or mutation |
| Inspect Summary | N/A — read-only | Current-authorized exact Workflow subject/status/lineage/limits/usage | Existing committed updates | Independent dossier state with meaningful next action |
| Change visibility | TASK-00390 Archive/Restore only | Current expected revisions, safeguard and original result | Existing visibility facts | Confirmed result membership change, never execution control |
| Follow and reconnect | N/A — durable reads through existing transport | Reload current durable state before following updates | TASK-00389 notifications, not authority | Fresh/stale/unavailable presentation with fenced late results |
