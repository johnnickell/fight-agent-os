## Validation and permissions

Use the accepted EPIC-00004 shell/design language, semantic tokens, Bootstrap mappings, theme behavior and component catalog as constraints rather than redesigning authentication or the global frame. Alternatives must differ meaningfully in repository scope/navigation, hierarchy/detail composition, information density, form/preview flow or Roadmap/queue interaction—not color alone.

Cover repository list/register/select, designated checkout and context summary/configuration/conflict; every Wayfinder/research/prototype/EPIC/TICKET/TASK/standalone type; hierarchy/history/criteria/evidence/dependencies/current/archive/render; semantic create/revise forms; closeout/reopen/Won't Fix/reparent/dependency/waiver/archive/restore; Roadmap/queue/order/override/reasons; migration inventory/rehearsal/approval/cutover/frozen/render state. Keep distinct Permissions and server authority visible without role-name assumptions.

Specify loading, empty, denied, not-found, stale revision, changed Repository/context, partial page, conflict, unavailable checkout/service, offline read-only, frozen Markdown, migration warning/failure and success. V1 forms have no autosave/persistent draft; show dirty-leave warning. Drag/reorder remains provisional until server success. Do not show generic status/document replacement, manual Blocked/Hold, coordinated-work start, claim, Agent chat or session affordances.

Use deterministic sanitized fake records and reports only. No real repository paths, instructions, evidence contents, credentials, service URLs or private identities enter artifacts/captures. Permission variants state client visibility is not security. Rendered Markdown/rehearsal output is clearly read-only/non-authoritative as appropriate.

Observe WCAG 2.2 AA-oriented semantics, labels, keyboard order/operation, visible/unobscured focus, announcements, contrast, target size, zoom/reflow, reduced motion, long content, tables-to-narrow transformation and guarded confirmation safety. Separate automated, manual, subjective and unverified evidence.

All artifacts/process/viewers remain under `.runs/prototypes/<scope>/`, loopback-bound where served, PID/port tracked and stopped. Production paths receive only durable handoff/completion evidence, never prototype implementation/assets.
