# Activate and enforce visible file screening across Pi workflow sessions

## Outcome

An operator enables file screening once for an approved project policy, then ordinary Pi and local `build`
parent/child sessions activate it automatically within that authority. Discovery content reaches an Agent only
after a current positive Jev decision or a validated, visible exception. The operator sees screening activity,
cache reuse, exceptions, blocks and actionable setup failures rather than unexplained ordinary reads.

This extends [TICKET-00039](../tickets/00039-TICKET.md) beyond the initial instruction-based delivery. It removes
the concrete adoption blocker in TASK-00162: hidden-by-default tooling, manually authored file policy and separate
manual allocations for every actual session ID. One implementation PR owns activation, admission and visibility;
no new Wayfinder session, general Agent scheduler or managed Workflow service is required.
