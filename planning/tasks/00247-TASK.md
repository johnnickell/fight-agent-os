# Connect manual Explorer sessions to authenticated scoped tools

## Outcome

Connect the reusable Agent authentication/use boundary to the existing manual Harness path and exercise one real
Team-assigned Explorer on the registered Fight Agent OS designated checkout/context. Return bounded source-cited
findings with current credential/session provenance, truthful denials and no new Workflow or disposable role demo.

## Scope

- In scope: Agent-specific integration at existing manual launch/session/tool boundaries; one human-approved
  read-only exploration, qualified Team/Agent/template/Repository/context/host/provider composition, safe current-use
  and unavailable-state feedback, cancellation/recovery handoff and attributable actual-result evidence.
- Out of scope: Building another Harness/provider client/Runner, browser Planning conversation, Planning database
  cutover, TASK claim/start, autonomous planning edits, all-eight-role acceptance, code mutation, general release
  authority or per-template certification ceremonies.
