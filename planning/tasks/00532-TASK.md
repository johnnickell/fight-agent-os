# Stage and recover an exact release candidate

## Outcome

John can stage exact CI-delivered application bytes, inspect actual target state, reconcile interrupted operations
and perform a compatible application-only rollback without data rewind. Executable operator operations and an
outage-accessible guide establish a useful staging release path, not a checklist-only demonstration or general
release engine. Production and the completed browser Planning journey are not prerequisites.

## Scope

- In scope: Fight-specific operator staging/promotion-input/recovery procedures, exact release identity and bounded
  approval checks, explicit schema/service changes, actual staging deployment and compatible rollback, independent
  health, interruption reconciliation and safe durable operational records/instructions.
- Out of scope: Production rollout (TASK-00533), rebuilding accepted artifacts, new release/Workflow/approval engine,
  managed Release Manager, live Planning cutover, implicit reverse migration/restore, CI-trigger changes, automatic
  branch/tag publication, optional features or standalone readiness/certification work.

|---|---|---|---|---|
| Stage exact bytes | Explicit bounded operator deployment and existing Doctrine operations | Complete artifact manifest/digests, current target/configuration/schema/services and authority | Safe attributed operational outcomes, not new Domain events | Only approved staging changes; no rebuild or production effect |
| Inspect candidate/release state | Read-only existing target/health observations | Requested versus observed release identity, independent service freshness and original outcomes | None from reads | Useful ready/partial/unknown/failed state without repair or deployment |
| Reconcile interruption | Explicit existing owner inspection/resume for the original operation | Actual artifact/schema/process state, current approval and unresolved liabilities | Existing owner facts only for real changes | Resume only supported remaining work; no blind migration/provider/mail replay |
| Roll back compatibly | Exact authorized application-only rollback | Current database and authority-mode compatibility, prior artifact/configuration and bounded target | Observed operational outcome | Replace application bytes only; otherwise stop for a separately approved recovery choice |
