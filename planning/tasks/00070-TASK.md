# Remove build and test self-verification bloat

## Outcome

Agent OS has a fast, comprehensible build gate that checks the current application without testing its own tools,
wrappers, configuration wiring, or deliberately seeded failures, backed by durable testing guidance and corrected
future quality requirements.

## Scope

- In scope: Remove the configuration-only composition test; replace the image-building gate with a thin running-service wrapper and PHP phase orchestrator; retain only Composer manifest validation, planning validation, Deptrac, and behavioral PHPUnit checks; remove redundant custom contract checkers and recurring negative fixtures; update engineering guidance and affected future TASKs.
- Out of scope: Product behavior, new architecture rules, dependency installation/auditing, coverage tooling, frontend checks, PostgreSQL implementation, and implementing future quality TASKs.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Run the current build gate | N/A — repository tooling | Validate the Composer manifest, planning, dependency direction, and owned behavior | N/A — no domain event | Named phases run once in the existing Compose service and fail clearly |
| Verify application behavior | N/A — PHPUnit tooling | Exercise externally observable owned behavior | N/A — no domain event | Product failures remain covered without configuration or tool self-tests |

## Validation and permissions

`./bin/build` must require the running `web` service and delegate to `scripts/build.php`. The PHP orchestrator may
use the locked Symfony Process dependency and must propagate phase output and failures. It must not install or audit
dependencies, build disposable production trees, generate invalid fixtures, or test whether its checks detect seeded
violations. Deptrac remains the dependency-direction authority.

No runtime permission applies. Repository tooling, tests, instructions, engineering documentation, and planning
requirements are authorized; product source and behavior are not.

## Acceptance criteria

- [x] The configuration-only composition PHPUnit test is removed while externally observable HTTP behavior remains covered.
- [x] `./bin/build` delegates through the running Compose `web` service to a PHP orchestrator with named phases and exact failure propagation.
- [x] The gate runs Composer manifest validation, planning validation, Deptrac, and PHPUnit once each without installs, audits, production-copy checks, or seeded-invalid self-tests.
- [x] Redundant custom architecture and production contract scripts are removed, and focused architecture execution uses Deptrac directly.
- [x] `AGENTS.md` and engineering standards prohibit product-suite tests of architecture, configuration, wrappers, build/planning/static-analysis mechanisms, generated files, and test infrastructure.
- [x] Affected future TASKs no longer require tests or recurring seeded evidence for wrappers, configuration, migrations, or quality tools while preserving meaningful behavior coverage goals.
- [x] Focused checks, planning validation, `git diff --check`, and the simplified `./bin/build` pass with fresh evidence.
