The test and production-contract baseline proves a small truthful Agent OS HTTP boundary rather than inherited Fight Common support compatibility. Application-owned root, unknown-route, and sanitized-error smoke evidence replaces obsolete fixtures, while the production source contract permits owned Domain/Application code and rejects copied Fight package source or namespaces.

## Scope

- In scope: Add deterministic Agent OS-owned root, unknown-route, and sanitized unknown-error smoke coverage; preserve correlation/logging evidence appropriate to the existing HTTP boundary; remove inherited support-campaign tests and fixtures after useful coverage exists; simplify test bootstrap; replace/rename the obsolete production public-contract check; permit legitimate `App\Domain` and `App\Application` code; reject copied `Fight\Common` and `Fight\AccessControl` source/namespaces; continue checking required production packages, autoload, and development exclusions.

## Validation and permissions

Smoke tests must use real Agent OS composition where practical, remain deterministic, and assert status, content type/envelope where applicable, sanitized output, and correlation/log behavior without requiring production-only failure routes. Test-only failure injection must be explicitly scoped and unavailable in production composition. Unknown exceptions must never expose arbitrary messages, traces, paths, secrets, or provider details.

Remove support-only Integration journeys and Messaging, Serialization, Socket, Security, and HTTP fixtures according to verified provenance; retain or rewrite only tests that describe current application behavior. Simplify `tests/bootstrap.php` to actual test needs. Do not replace inherited breadth with tests of Markdown, wrapper text, or upstream package behavior.

The production contract must allow `src/Domain` and `src/Application` under the `App\` namespace, continue proving required Fight packages and production autoload are present, prove development packages are absent, and reject vendored/copied `Fight\Common` or `Fight\AccessControl` implementation beneath owned source. Contract checks must fail clearly and without mutating the tree.

No runtime permission model applies. Approved scope permits application smoke tests, test-fixture removal, and production-contract/build updates; it grants no product behavior, upstream modification, or security-policy expansion.
