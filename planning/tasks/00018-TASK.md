# Establish the versioned JSend API interaction boundary

## Outcome

Agent OS has an explicit `/api/v1` JSON composition boundary that proves one final Action dispatching one command, query, or justified orchestrator and delegating successful output to an endpoint-specific Responder using an explicit safe View, JSend, and snake_case transport mapping without inventing a product endpoint.

## Scope

- In scope: Versioned API route/composition convention; final single-interaction Action shape; CQRS dispatch injection; endpoint-specific successful Responder; explicit safe response/View model; camelCase-to-snake_case mapping; JSend success envelope and JSON content type; the smallest genuine production interaction that traverses real application HTTP composition; replacement of incompatible inherited response assumptions.
- Out of scope: Authentication/invitation/account endpoints, product policy, persistence, validation middleware, centralized exception classification, OpenAPI publication, CORS, entity serialization, and reusable abstractions without more than one demonstrated need.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Dispatch representative write interaction | One package/fixture command only when selected for proof | N/A for a command proof | Events remain owned by selected behavior | Action maps request and dispatches once; Responder emits documented safe success |
| Dispatch representative read interaction | N/A for a query proof | One package/fixture query returning an explicit safe View | N/A — read-only | Responder maps View to snake_case JSend JSON |
| Compose versioned route | N/A — route setup | Inspect route metadata and injected Action/Responder/bus | N/A — no domain event | `/api/v1` group resolves dependencies without service-location from business code |

## Validation and permissions

Select the smallest genuine production interaction that needs the HTTP boundary without creating an authentication, invitation, authority, or fabricated observability endpoint. Do not create a test-only route, fake use case, or configuration-wiring test merely to prove composition. If no honest interaction is available, revise this TASK's dependencies or scope rather than manufacturing one.

Actions are final, map transport input, dispatch exactly one command/query/explicit orchestrator, and contain no business, persistence, authorization, or response policy. Endpoint-specific Responders own successful representations. Explicit Views/response models contain only approved fields; package entities, credentials, grants, hashes, internal exceptions, and arbitrary objects cannot be serialized directly.

PHP properties remain camelCase; explicit boundary mapping emits snake_case. API output uses JSON and JSend consistently with deterministic status/content type/body. Unsupported non-JSON assumptions fail safely without enabling CORS.

No end-user permission is implemented. HTTP composition, safe fixture, and focused tests are authorized; product endpoints are not.
