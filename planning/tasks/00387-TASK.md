# Search stable history and scope-labelled summaries

## Outcome

Authorized consumers can find every accessible Workflow in a stable Current or Archived result, inspect selected
phases and read truthful operational summaries without page-local search, arbitrary history caps or fabricated
usage. Browser components consume these server contracts later rather than define another query authority.

## Scope

- In scope: Whole-result safe metadata search, stable snapshot/cursor semantics, bounded list/detail/phase/evidence
  queries, independent Running now summary and integration of early visibility plus measured usage/time facts.
- Out of scope: Archive/Restore mutation policy, accounting/forecast computation, browser components, another index
  service, raw logs/transcripts/Artifact-body search and synthetic PR, Review, usage or quota facts.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Find current or archived work | N/A — read-only | Whole-result repository metadata search and stable Newer/Older cursors | N/A | Bounded complete discoverability, no visibility or execution change |
| Inspect selected work/phase | N/A — independently bounded reads | Exact semantic state, safe activity and authorized evidence links | N/A | Explicit source, freshness and unavailable/partial detail |
| Inspect operational summary | N/A — read-only | Independent Running now, Needs Human, meaningful outcomes and owning usage/time facts | N/A | Permission-filtered scope-labelled facts, not inferred accounting |
| Project owned source changes | Existing bounded projector operation | Committed visibility/usage identities and expected source generations | Committed derived-view changes only | Idempotent safe summaries with no new source policy |
