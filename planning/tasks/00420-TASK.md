# Publish and verify the original initial commit

## Outcome

The exact original generated commit is published to the confirmed GitHub repository and selected default branch.
Local remote configuration, non-force push and default-branch effects form one independently reviewable publication
outcome but retain separate durable original intents/results and reconciliation after partial failure.

## Scope

- In scope: Protected exact local remote setup, initial-subject push, default-branch establishment/verification,
  actual local/provider identity checks, partial-effect recovery and safe publication results.
- Out of scope: Additional commits, publication of preparation changes, force-push, unrelated refs, remote adoption,
  key/login enrollment, PR/review/merge/release, cleanup and browser/attempt-transition ownership.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Configure intended remote | Execute exact admitted remote-setup operation | Owned local Git identity, native remote identity and original result | Verified owning stage facts | Only the intended remote configuration |
| Publish initial subject | Execute original admitted non-force push | Exact initial OID/tree/branch, current target identity/ref and authority | Verified push fact or uncertainty | Confirmed initial commit on selected remote ref only |
| Establish default branch | Execute exact original default-branch operation | Verified pushed ref/OID and current provider state | Verified default/publication fact | Selected remote default, no unrelated source-host changes |
| Recover partial publication | Explicit per-effect original reconciliation and proved-safe continuation | Actual local remote, native provider identity, refs/default and prior results | Verified original outcome or hold | No duplicate/retargeted effect or false completion |
