# Search through protected Brave access

## Outcome

An authorized Agent can obtain useful compact attributable public search results through first-party MCP without
receiving a Brave key, raw unscreened snippets or arbitrary network access. Search remains independent of page
retrieval and usable without completed Artifact inspection or browser Planning.

## Scope

- In scope: First-party search Tool/application Query, injected Brave HTTP adapter, protected installation settings,
  exact search/disclosure admission, bounded screened results, original correlation, usage and operator guidance.
- Out of scope: Page fetching, broad crawling, browser automation, provider-platform abstraction, public credentials,
  general cache, Planning mutation and retained/cached/resumed web delivery before TASK-00384 qualification.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Search public references | N/A — application Query, not business mutation | Current authorized bounded query/count/filters/page | Safe request/usage/screening observations | Protected Brave request and separately authorized Jev evaluation |
| Deliver compact results | N/A — bounded query result | Exact screened source representation and current delivery authority | Safe delivered/partial/withheld facts | Attributable results only, no automatic page retrieval |
| Inspect availability/outcome | N/A — status is read-only | Redacted config/limits and original operation state | N/A | Honest denied/unavailable/unknown outcome; no request on inspection |
| Stop outstanding work | Existing owned cancellation | Original dispatch/result and current generation | Actual stop/outcome facts | Bounded cancellation, retained uncertain cost and no blind retry |

## Validation and permissions

Consume TASK-00381 and transitively the existing TASK-00171/00245/00244 protected evaluator, MCP registry and
current-use broker. Expose one capability through the actual package Tool metadata and current authorization on
discovery and every invocation, including direct/CLI paths. Enforce separate exact search Permission, applicable
human/Workflow delegation, assignment/Repository/environment, host and current configuration. A Skill, alias, cached
catalog or model-supplied identity is not authority. No second MCP server, HMAC signer or privileged Jev principal.

Minimize query inputs and authorize outbound Brave disclosure separately from local access and Jev disclosure.
Reject prohibited credentials/private source/personal data under supported deterministic disclosure policy; an
Agent-supplied query is not consent. Use strict bounded query/count/filter/pagination shapes and aggregate request,
time/concurrency/spend limits. Provider pagination cannot silently broaden scope or continue after authority loss.

Use operator-controlled installation-held Brave credentials and a fixed qualified provider destination through the
injected HTTP capability. Configure and inspect redacted availability without automatic calls or account enrollment.
Keep keys outside child environments, source, prompts, transcripts, logs and Artifacts. Do not forward provider
credentials across redirects or select another provider after failure. Direct Brave API/MCP and shell-network
fallback stay unavailable; default-deny sandbox networking is unchanged.

Build the compact exact result representation before TASK-00381 evaluates it; release source-controlled titles,
snippets and labels only after matching admission. Preserve provider/query/page identity, source URLs, coverage and
actual observation time without fabricating quotations or claiming a snippet is a page read. Safe trusted failure
metadata must not echo withheld source. Report partial, unavailable, denied, timeout and unsupported results honestly.
Oversized raw material is unsupported until its qualified TASK-00384 Artifact route exists, not silently truncated
and reported as completely screened.

Record bounded sanitized original request/attempt/evaluator correlation and available provider usage. Reuse owning
reservation/intent participants where applicable, retaining unknown outcomes and possible charges across cancellation
or lost response. Any required state/audit/intent commits canonically before external effects; inspection cannot
retry the provider. Fresh authorization alone does not reconcile an ambiguous earlier request or reset spending.

This slice releases only fresh bounded results through a qualified live context. Retained/cached/resumed web routes
remain unavailable until TASK-00384 integrates exact-content admission: persisted Pi context or an old result cannot
be automatically restored as a shortcut. Gate unsupported routes explicitly rather than claim safe reuse. Source
instructions never authorize follow-up retrieval, tools, policy changes or additional disclosure.

## Acceptance criteria

- [ ] An actual authorized Agent obtains useful scoped Brave results through protected first-party MCP with exact
  provenance and mandatory screening; no provider key or unscreened source reaches the child.
- [ ] Revocation, invalid context/input, denied disclosure and missing setup prevent dispatch/delivery across entry
  paths; provider pagination and credentials cannot escape the qualified destination/scope.
- [ ] Limits, cancellation, partial results and unknown provider outcomes retain original correlation/liability;
  no silent fallback, repeated charged request or fresh-success claim follows uncertainty.
- [ ] Unqualified large/retained/cached/resumed routes remain unavailable, while ordinary compact search does not
  depend on completed page retrieval, browser delivery or evidence retention.
