# Generate through protected local Codex

## Outcome

A real authorized Planning conversation generates through independently qualified local openai-codex under Pi/
provider-owned authentication, even when OpenRouter is absent. Agent OS consumes protected results and safe
readiness facts, never imports the user's provider credentials or silently falls back to an unprotected child.

## Scope

- In scope: Exact supported Pi/openai-codex authenticated integration, protected local invocation/host boundary,
  admission/stream/outcome/status/stop composition, actual Planning consumption and safe operator guidance.
- Out of scope: New provider login/credential lifecycle, copying auth files, new session/queue engine, OpenRouter
  dependency, additional providers, automatic routing, final browser journey and duplicate switching UI.
