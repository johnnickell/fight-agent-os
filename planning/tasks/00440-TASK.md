# Publish and recover instruction changes in the Dashboard

## Outcome

A human separately previews and confirms publication from the existing instruction form, follows the original
operation through partial Git/GitHub effects and safe return, and opens the exact PR handoff. The browser never
confuses a saved draft, committed change, pushed branch, PR, return or human merge, nor replays a lost operation.

## Scope

- In scope: Existing Dashboard publication preview/confirmation, original status/stop/recovery, PR detail/link,
  retained-local-state warnings, currentness/permission/race handling and real integrated publication evidence.
- Out of scope: Another editor/session/workspace, browser credentials, AI prerequisite, managed Review, Agent
  submission, approval/merge, sync implementation, current-branch push alternative and destructive cleanup.

| Use case | Commands | Queries | Events | Expected side effects |

| Confirm plan | TASK-00436 exact human confirmation | Current plan/applicability and authority | Existing admitted-operation facts | One original publication operation, not Agent acceptance |

| Open PR handoff | N/A — explicit validated external navigation | Native PR identity/title/base/head/OID and observation freshness | N/A | GitHub new-tab handoff, no approval, merge or automatic sync |
