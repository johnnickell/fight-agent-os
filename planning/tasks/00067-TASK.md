# Add the read-only next-work router skill

## Outcome

Provide a project-local `next` skill that reads the authoritative planning surfaces and recommends the current
executable TASK and available Wayfinder decision without starting either workflow.

## Scope

- In scope:
  - Add an explicitly invoked `.pi/skills/next/SKILL.md` informed by the reviewed `ask-matt` and
    `writing-for-agents` references.
  - Follow `planning/CONVENTIONS.md` for TASK selection and active Wayfinder frontier interpretation.
  - Return copyable skill invocations and clear no-work or ambiguous-priority results.
- Out of scope:
  - Starting `work`, Wayfinder resolution, or any other recommended skill.
  - Changing planning priority, Wayfinder schema, or another skill's behavior.
  - Importing Matt Pocock's skill suite or source wording.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Ask what planning work is next | `/skill:next` | Read the Board, active Wayfinder maps, and relevant records | N/A — read-only router | Print TASK and Wayfinder recommendations without modifying planning or invoking another skill |

## Validation and permissions

The skill must validate the generated planning surfaces before trusting them and surface stale or invalid planning
instead of guessing. It reads repository-owned Markdown only and grants no implementation, publication, merge, or
planning-mutation authority. Application permissions and the shared security process are not applicable because
this chore adds no runtime behavior.

## Acceptance criteria

- [x] `/skill:next` is explicitly user-invoked and has a concise human-facing description.
- [x] TASK selection follows `planning/CONVENTIONS.md`: continue active work; otherwise choose the first executable
      Ready Frontier entry; report when none exists.
- [x] Wayfinder selection examines every active map, respects each authored Frontier and open dependency state,
      and does not invent a global priority when multiple map frontiers are available.
- [x] Recommendations identify the planning record, explain why it is available, provide a copyable next skill
      invocation, and stop without starting work.
- [x] Closed maps, closed decisions, blocked decisions, stale generated views, and empty frontiers produce explicit
      results rather than fabricated work.
- [x] The skill's claims about `work`, `wayfinder`, and any mode-specific recommendation come from their current
      `SKILL.md` files, not cached summaries.
