# Rehearse and compare complete PostgreSQL import

## Outcome

Authorized migration preview can import one proposed complete baseline into a guarded empty rehearsal target, rebuild and compare all authoritative Planning state, projections, renders and canonical queue results, and produce a deterministic report without changing Repository authority or production Planning state.

## Scope

- In scope: `RehearseMarkdownPlanningImport`; isolated PostgreSQL rehearsal target identity/ownership/empty-state guard; migration attempt/CutoverId and operational stages; import of TASK-00099 baseline streams, references, constraints and order; TICKET-00026 projection rebuild and TASK-00027 Roadmap/queue evaluation; deterministic source-to-target identity/reference/content/hierarchy/lifecycle/archive/dependency/order/evidence/render/queue comparison; complete mapping/warning/rejection/accounting report and digests; same-source two-run equivalence; safe failure diagnostics; discard/cleanup of only proven rehearsal-owned state; migration-preview Permission; API/console operations; rollback/concurrency evidence.
- Out of scope: Human rehearsal approval, production target writes, authority-mode change, Markdown freeze/edit, warning waiver/repair, browser ceremony, promoting prototype SQLite, post-cutover writes and source retirement.

Before mutation, require explicit rehearsal mode, allowlisted target identity, migration-specific ownership token/CutoverId, current user/schema evidence, zero Planning streams/constraints/projections and no Repository authority binding. Reuse guarded database protections; never infer safety from a name alone or run request-time schema creation outside versioned migrations.

Revalidate manifest, mapping, importer/event/projection/template/eligibility schemas and source provenance before import. Import self-contained baseline events through production TICKET-00026 append/constraint/projection contracts, preserving mapped identities/references. Operational rehearsal evidence is separate from aggregate history. Import failure rolls back all attempt state where transactional; any external staged evidence remains clearly failed and cleanup-owned.

Rebuild all current/history/hierarchy/constraint projections, render typed Markdown and invoke TASK-00096/97 canonical ordering/eligibility on the rehearsal target. Compare source/mapping/target counts, identities, references, slugs, stable children, lifecycle/archive, parents, dependencies/cycles, authored/supplemental/unclassified content, criteria/evidence/delivery, Roadmap/TASK order/overrides, projection digests, rendered semantics and queue reason/order. Generated/non-semantic formatting differences are explicitly classified; no mismatch is normalized away.

Report every manifest item and generated artifact as imported/represented, inventory-only, explicitly expected generated difference, warned or rejected.
