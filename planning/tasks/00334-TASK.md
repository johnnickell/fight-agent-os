# Inspect effective Skill aliases and resolve collisions

## Outcome

Users inspect bounded effective Skill choices and deliberately resolve personal/project/database collisions.
Custom-Skill publication receives precise host observations without waiting for completed publication or loading.

## Scope

- In scope: Authorized database catalog/reference facts plus bounded local Skill observations, visible alias
  collisions, readable qualified alternatives/picker, explicit choice provenance and publication-facing freshness.
- Out of scope: Remote byte loading, custom publication, another catalog/authority, general filesystem scans,
  session creation, user-profile storage, silent configuration edits and overriding live permissions.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect effective choices | N/A — bounded authorized observation | Exact database identities/revisions, declared local Skill locations, aliases and scope | N/A — enumeration changes no authority | Visible complete-for-declared-scope catalog or explicit incomplete result |
| Resolve a collision | Explicit bounded selection/choice under existing owner | Exact competing identities, intended scope and current observation generation | Safe selection provenance, not resource publication or a grant | Deliberate qualified choice; no automatic activation |
| Validate publication choice | N/A — inspect candidate-bound current observation | Exact candidate, target scope, observed catalog and resolution freshness | N/A | Valid choice or stale/unknown hold for TASK-00328 |

## Validation and permissions

Use TASK-00327's current authorized database metadata and TASK-00333's exact origin binding. This early path can
inspect catalog facts through their existing protected resource adapter; it does not require TASK-00335's completed
Agent MCP transport or TASK-00336's loader. Do not add a parallel server/catalog merely to provide observations.
Observe only declared supported personal/project Skill locations with bounded sizes, traversal and time. Never
scan the home directory or return unrelated private paths/content to the server, model or diagnostics.

Keep logical/revision/origin identity distinct from human aliases. Personal/project filesystem Skills win a bare
alias over MCP only with visible collision evidence and an accessible qualified alternative. Personal-versus-project
conflicts require a picker or explicit saved repository/profile choice; host discovery order is not resolution.
Keep useful short commands. A qualified name identifies the intended resource, not a replacement trust grant.

Bind observations and deliberate choices to actual host/source set, scope, relevant generations and exact candidate
where publication consumes them. Current access applies to every disclosed database entry. Incomplete enumeration,
unknown host coverage or changed observations cannot prove collision freedom. Define exact freshness/validation
semantics for TASK-00328, including how the trusted host supplies evidence without making arbitrary client assertions
authority. Local filesystem changes cannot be transaction-locked by a remote database; later loading rechecks actual
choices and cannot promise permanent alias uniqueness from a previous observation.

Keep read-only inspection and transient selection useful without completed database profile persistence. Any saved
profile choice goes through its existing owner when available; otherwise report that persistence unavailable rather
than inventing another preference store. Selection neither publishes a custom Skill nor reads/activates remote
content. TASK-00336 integrates it with actual protected discovery/loading and snapshot provenance.

Use shared expected-state/reference semantics for authoritative changes and ADR 0002 where database state is
mutated. External filesystem observations stay outside business transactions. No events for ordinary reads; safe
selection observations expose no private resource bodies, handles or credentials. Preserve existing local Skills.
