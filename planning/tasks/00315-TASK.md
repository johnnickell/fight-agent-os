# Publish one recoverable GitHub PR

## Outcome

Release Manager publishes the exact accepted and verified candidate to one GitHub PR through a protected,
recoverable non-force capability. Unknown external outcomes never become duplicate PRs or false delivery success.

## Scope

- In scope: Release-Manager-only source-host broker capability, durable exact publication intent, constrained
  non-force push/create-or-update PR operations, independent provider verification and original-effect recovery.
- Out of scope: Arbitrary GitHub tools, raw credential delivery to Agents, force-push, approval/merge, remote-branch
  deletion, signing, release/deployment, artifact reachability/cleanup/final handoff owned by TASK-00316.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Admit exact publication | Intent-specific publication authorization | Current acceptance/QA/candidate, live authority, Repository and configured base/branch | Durable publication intent or denied fact | One bounded original operation before external use |
| Push and create/update PR | Protected exact non-force push and PR operation | Original intent, provider-native Repository/PR identity and current remote OID | Attributable effect outcome/uncertainty | Accepted candidate on Workflow branch and one matching PR |
| Reconcile original result | Original-effect reconciliation before any safe retry | Actual remote commit, native PR identity/base/head and prior outcome | Verified/held publication facts | Known original result or explicit uncertainty, not a new request escape hatch |
