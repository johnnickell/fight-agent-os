# Port the Harness session-file birth helper to PHP

## Outcome

Remove the live Python session-file birth helper without changing how the Harness admits, identifies, or rejects session files.

## Scope

- Trace the existing `harness/pi/src/observation/session-file-birth.py` callers and package paths. Migrate the helper, its source and installed callers, and affected checks to PHP together. Preserve the supported result and failure contract without adding a compatibility shim.
- Preserve native behavior, session and checkout authority, and the existing boundaries for runtime evidence. Qualify the PHP runtime used by supported native and packaged callers; do not treat Docker-only evidence as proof that an installed caller works.
- Remove the replaced Python helper after verifying the surviving paths. Do not change the stage launcher or monitor except to coordinate shared contracts with [TASK-00617](00617-TASK.md).

## Acceptance criteria

- [x] Source and packaged callers run the PHP helper and preserve admission, identity, and refusal outcomes on supported native paths.
- [x] Existing owning checks and bounded native probes verify both successful observation and rejected inputs without broadening role or file authority.
- [x] The package contains the replacement, and no surviving caller needs the old helper.

## Verification and evidence

Record supported runtime capabilities, exact commands, source and installed-package results, and bounded refusal probes. Report gaps rather than treating a mock as native evidence. Hand off to independent Review and applicable QA.

## Coordination

No prerequisite TASKs. Coordinate any shared test setup with [TASK-00615](00615-TASK.md) and shared observation files with [TASK-00617](00617-TASK.md). Planning approval does not select a checkout or authorize implementation or publication.
