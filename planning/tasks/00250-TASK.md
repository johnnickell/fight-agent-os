# Bind role selections to isolated immutable Agent sessions

## Outcome

Integrate exact role-profile selection with existing protected Harness session owners so each participating Agent
retains its own identity, bounded authority and immutable profile/context provenance. Current use remains live;
no session can become another role or inherit another Agent's power by changing a prompt or alias.

## Scope

- In scope: Agent profile integration with owned session/snapshot operations, separate Agent/holder/session
  bindings, applicability and current scope checks, role independence facts, stale-state handling and safe
  model/provider provenance; supported actual session integration and denial qualification.
- Out of scope: New launch/Workflow engine, snapshot store, credential broker, Team roster, Agent creation,
  browser Planning conversation, full role outcomes, independent review verdicts, hotfix repair or deployment.
