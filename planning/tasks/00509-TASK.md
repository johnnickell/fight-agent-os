# Patch repository-owned runtimes and tooling affected by October security advisories

## Outcome

Remove the affected PHP, Node.js, Storybook and NGINX versions from this repository's supported local
application and engineering paths, qualifying rebuilt images and the locked client graph against the
October 2026 advisories. Preserve authentication, HTTPS and catalog behavior. This is one bounded security
maintenance PR for existing application delivery, not a general security platform or an assertion that all
47 issues in the linked roundup affect Fight Agent OS.

The maintainer requested creation of this bugfix TASK in an isolated worktree from
[the reported roundup](https://dly.to/ywMUdBWlrup). Record creation and the bounded report-derived scope are
authorized. This was the creation-time authorization boundary; the subsequent delegated implementation
is recorded below. Acceptance, publication, deployment and incident response have not occurred.

## Scope

- In scope:
  - Qualify PHP 8.5.12 or a later supported patched 8.5 release for both CLI/web and FPM images. Replace the
    affected FPM pin and make the CLI build/rebuild path demonstrably use a patched runtime rather than
    treating its floating `8.5` tag as evidence about cached images.
  - Qualify Node.js 24.22.1 or a later patched 24.x release; synchronize the image digests in CLI, browser
    tooling and `bin/client`, client engine metadata/lock and current runtime documentation. Preserve
    intentional npm/Playwright compatibility, updating those only where required by this repair.
  - Qualify Storybook 10.6.2 or a later patched 10.x release and compatible first-party addons, deliberately
    regenerate the client lock and retain the upstream origin protections without insecure escape flags.
  - Replace the local HTTPS NGINX image with a supported patched release (upstream identifies 1.30.6+
    stable or 1.31.7+ mainline for the referenced fixes); verify configuration and application behavior.
  - During these owned image rebuilds, record OS/CA-package and Node trust-store provenance and qualify
    the reported eMudhra remediation against vendor evidence. A missing vendor fix remains an explicit
    blocker for the affected owned image, not a reason to disable certificate verification.
  - Record exact selected versions, image digests, before/after checks, restart/rebuild instructions and
    any residual exposure or operational action requiring separate authority.
- Out of scope:
  - Exploit execution, production scans, live-service interruption, deployment, secret rotation, or claims
    of compromise/cleanup. Those require separate operator authority and evidence.
  - Host-wide Pi/Node/Python/Go upgrades, unrelated repositories, external infrastructure or a blanket
    upgrade of every component named in the roundup. Do not pin Pi to a version.
  - Framework migration, dependency modernization unrelated to these fixes, new security automation,
    product-suite tests of Dockerfiles/manifests/wrappers, or speculative infrastructure demonstrations.
  - Assuming LiteLLM, Railway, GitLab, Laravel, Next.js, Plex or other reported products are deployed here.
    Escalate newly demonstrated exposure rather than silently broadening this TASK.

The final query returned 10.4.6 for both locked packages. Compare the observed versions with these primary
sources, retrieved successfully during diagnosis:

- [PHP security announcement](https://www.php.net/archive/2026.php): CVE-2026-109618 (OOM corruption)
  and CVE-2026-109619 (stale request state); PHP 8.5.12 fixes both on the 8.5 line.
- [PHP Foundation explanation](https://thephp.foundation/blog/2026/10/21/todays-php-security-release-and-how-were-strengthening-php-security):
  runtime-level defects; framework updates are not a substitute. FPM is among affected SAPIs.
- [Node October security release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases):
  24.22.1 includes Brotli CVE-2026-111497, DNS/TLS fixes and eMudhra CA changes. Not every listed CVE
  affects every Node line; use its per-line applicability rather than copying the roundup wholesale.
- [Storybook maintainer advisory](https://github.com/storybookjs/storybook/security/advisories/GHSA-f2ph-cmg5-wxc8):
  CVE-2026-114125 affects 10.0.0 through versions below 10.6.2. Interactive development servers are
  affected; static builds/headless-only use are excluded by the advisory. `bin/client storybook-dev`
  binds host loopback and mounts source read-only, reducing effects but not proving the upstream issue absent.
- [NGINX security advisories](https://nginx.org/en/security_advisories.html): 1.28.3 is in the version ranges
  for CVE-2026-15176 and CVE-2026-97205, among others, but not CVE-2026-93479's listed ranges.
  Preserve configuration-specific applicability distinctions when selecting the replacement.

Root cause at the repository boundary: declared runtime/tooling selections predate upstream security fixes.
Confidence is high for the PHP FPM and Storybook affected-version findings, with Node digest execution,
actual running image state, CA remediation and exploit reachability still unverified. There is no evidence
here of successful exploitation or credential exposure. Deliberately reproducing memory-corruption/RCE on
shared services is unsafe and unnecessary for confirming these dependency defects.
