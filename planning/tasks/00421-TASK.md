# Inspect and clean separately authorized remote resources

## Outcome

An authorized human can inspect the exact impact of cleaning an operation-owned GitHub repository and, only after
separate current consent, obtain a verified removed/retained/uncertain result. Partial creation can be cleaned
without requiring successful publication; replaced, unrelated, referenced or uncertain resources stay protected.

## Scope

- In scope: Protected remote impact inspection, actual provider cleanup adapter, ownership/reference/currentness
  composition, bounded original-effect reconciliation and safe retained history.
- Out of scope: Browser confirmation, new cleanup authority/attempt state machine, local filesystem or remote-config
  cleanup, registration/context/snapshot deletion, account enrollment and automatic compensation.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Inspect exact remote impact | N/A — explicit authorized read-only inspection | Native identity, operation ownership, current state/references and irreversible impact | N/A | Fresh bounded impact facts or refusal, no deletion |
| Clean confirmed remote | Execute TASK-00413's exact admitted provider cleanup | Current separate consent, native target, exclusion and authority | Verified cleanup facts through attempt owner | Only the exact separately approved provider effect |
| Reconcile interrupted cleanup | Explicit original-operation inspection and only proved-safe retry | Actual original disposition and protected retained resources | Removed/retained/uncertain facts | No retargeting reused names or blind deletion |
| Inspect cleanup history | N/A — ordinary read | Authorized retained original consent/outcome/provenance | N/A | No live provider inspection, deletion or replay |
