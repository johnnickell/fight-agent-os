# Admit disclosure-approved budgeted generation

## Outcome

A real authorized assignment can admit one exact disclosure-approved generative request with durable bounded
capacity reserved before any external effect. Denied or uncertain admission cannot dispatch work or acquire a
fresh budget merely by retrying.

## Scope

- In scope: Protected application admission and safe inspection, independent disclosure/provider policy,
  minimized approved context, finite input/output/time/concurrency/aggregate-spend limits, durable reservations,
  original request correlation, audit and currentness fences.
- Out of scope: New assignment/grant/session/queue engine, provider transport/authentication, result accounting,
  automatic routing, proposal validation/application, Jev or speculative quota Dashboard.

| Use case | Commands | Queries | Events | Expected side effects |

| Admit exact generation | Owning expected-state request admission with original operation/attempt identity | Current assignment, disclosure, provider/model, host and remaining limits | Committed admission/reservation fact | Required intent, reservation and audit commit together before dispatch |

| Reject stale or excessive work | Owning admission command rejects | Current generations, scope, provider qualification and safe cost bound | Only actual committed owning facts | Zero new dispatch; prior reservations and uncertain work remain intact |
