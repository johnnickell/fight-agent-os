# Create one named Team-bound Agent from retained intent

## Outcome

An exact human-confirmed creation intent establishes one distinctly named Agent with one Team, immutable reviewed
template/Repository-scope binding, its own protected holder-bound issuance and complete eligible initial direct
Permissions. Recovery resolves that same intent without creating another Agent or presenting incomplete setup as
finished or usable. This supplies creation to existing role/session/roster consumers, not a new launch engine.

## Scope

- In scope: Owned confirmed creation crossing template/Team/package boundaries; retained original intent and
  correlation, supported binding/initial-assignment composition, complete current authorization/reference checks,
  safe status/recovery and protected Application/API entry. Required state/audit and failure semantics are explicit.
- Out of scope: Duplicate credential queue, unteamed product Agents, redefinition of package transitions, raw
  secret delivery, session launch, editor/publication, existing-Agent drift reconciliation or live cohort enablement.
