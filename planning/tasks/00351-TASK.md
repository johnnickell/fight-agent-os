# Execute admitted turns through one protected runtime

## Outcome

One production invocation path joins durable input/attempt ownership, exact immutable snapshots, verified resources,
current tool/provider admission and the protected runtime. OpenRouter/Codex owners can qualify real Planning
consumption through this path without another launcher, session store or disposable proof endpoint.

## Scope

- In scope: Protected activation/execute/result path for a bounded conversation turn, application/runtime identity
  mapping, current-authority/acting-window composition, durable result/progress and finite turn limits.
- Out of scope: Provider transport/authentication/accounting duplication, full browser Planning, Workflow execution,
  role identity creation, proposal acceptance, final checkpoint recovery and a second queue or sandbox.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Activate one exact turn | Owning execution command for committed original input/attempt | Current assignment, owner, snapshots, loader, host and provider admission | Confirmed owning activation/progress/result facts | One bounded turn through qualified effect adapters, never another assignment |
| Invoke a protected effect | Existing current-use/tool or provider admission operations | Actual current scope, acting window and remaining limits | Existing owning effect/outcome facts | Exact admitted effects only, outside business transactions |
| Wait or retain result | Owning exact-attempt result/wait operation | Pending question/input and original effects | Committed result/wait facts with safe progress | Durable continuation point; no model-authored approval or artifact mutation |
