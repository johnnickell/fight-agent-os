# Repair file-screening preview, interactive noise and screenshot reads

## Outcome

An operator can inspect the complete file-screening enrollment preview in a short terminal before deciding
whether to save standing authority. This removes the reported setup usability blocker in TASK-00309 without
changing its standing enrollment, credential or accounting contracts. The operator-approved follow-up also removes
routine interactive diagnostic noise and restores direct screenshot reads without sending images to the text-only
relevance evaluator. John's subsequent clarification removes the image-specific selection/approval system:
commands receive risk assessment and images read directly. The October 16 follow-up allows direct project text
reads with strongly encouraged Jev discovery, portable instructions and role-scoped explicit writes.

## Scope

  concise final confirmation tied to the same candidate. Preserve exact preview content and existing save behavior.
- In scope (operator-expanded October 15): Silence routine TUI JSON/status/event notifications at startup and
  during normal turns; retain concise actionable warnings, explicit inspection and private noninteractive monitor
  observations. Read bounded supported images directly, including external Desktop paths, with native Pi image
  results and unchanged sensitive-path restrictions. No image-selection state, command or approval dialog.
- In scope (operator follow-up): Keep Codex weekly usage on its own footer row, with file screening and Jev together
  immediately below. Present unchecked-but-configured Jev as `configured`, without running a billed self-check.
- In scope (October 16 repair): Correct the reported command-disclosure false positives for quoted census labels
  and `.env.example` manifest references; return actionable command-local recovery through native shell errors.
  Preserve real credential checks, command-risk assessment, one-command decisions and authority/accounting rules.
- In scope (October 16 operator expansion): Direct ordinary project reads; strongly encouraged Jev for unfamiliar
  discovery; portable core/native/linked instructions; Engineer/Land normal writes and Reviewer/QA `.runs` writes;
  `.env.example` access with secret/runtime exclusions retained; role-aware assessment of every final command.
- Out of scope: Enrollment/budget policy changes, diagnosing the separately reported opaque setup error unless
  reproduced by these paths, live enrollment, provider requests, and runtime qualification expansion. Preserve
