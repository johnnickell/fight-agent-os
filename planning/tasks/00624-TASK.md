## Outcome

Keep `./bin/qa` preparing and cleaning up isolated human QA scenarios without the Python QA setup code.

## Scope

Port the live human QA and scenario setup commands to PHP. Use the shared PHP lifecycle path; preserve scenario selection, fixture isolation, explicit setup, resource ownership, and cleanup on failure. Do not change QA role authority, acceptance, or the ingress command contract.

## Acceptance criteria

- [ ] The existing command prepares a supported scenario and leaves the expected isolated fixtures.
