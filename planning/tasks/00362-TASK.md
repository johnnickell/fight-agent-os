# Conduct Wayfinder interviews and create reviewed maps

## Outcome

A planner answers or corrects the exact Wayfinder question, reviews an editable map proposal and explicitly creates
it through existing semantic operations. Opening the map resumes its current decision; progress reflects known
required decisions rather than model activity. This delivers the real browser interview/map path in one bounded PR.

## Scope

- In scope: Question/answer/correction UI, map title/slug/destination/done-condition/initial-decision preview,
  explicit atomic map creation, current/eligible decision navigation and honest decision-unit progress.
- Out of scope: Another Planning model/allocator, automatic EPIC creation, AFK execution integration owned by
  TASK-00364, coding work, automatic preference choices and autosaved manual preview edits.

## Use cases and contracts

| Use case | Commands | Queries | Events | Expected side effects |
|---|---|---|---|---|
| Answer or correct | Exact human answer/correction through TASK-00356 | Pending question, prior accepted answer and expected revisions | Owning input/DecisionPoint facts | Durable answer history, not model-selected preference |
| Review and create map | Explicit reviewed candidate Create through TASK-00359 | Complete typed preview, current scope and slug/relationship validation | Owning accepted map/decision and proposal facts | Complete reviewed map set or no partial hierarchy |
| Open current decision | Authorized attach/navigation; bounded advance only within accepted intent | Current frontier, dependencies and known decision counts | No invented completion event | Current question or honest unavailable/blocked state |

## Validation and permissions

Consume TASK-00361's exact intake/selection and TASK-00359's complete candidate/answer/atomic-Apply chain. New-artifact
answers remain durable input until explicit creation; existing DecisionPoint answers/corrections use their semantic
owner. Require current intent-specific rights, exact question/candidate generations and expected aggregate/graph
revisions. Duplicate submissions inspect original outcomes. Competing answers or slug claims reject safely, preserving
accepted input and useful candidate history. No client-generated authoritative IDs or last-write-wins replacement.

Preview title, mutable repository-unique slug, destination, done condition, initial decisions/dependencies and
frontier as typed fields. Explicit Create commits the reviewed set before advancing to its first eligible decision
within the authorized operation. Lost acknowledgement must resolve creation before another Create or advance.
Map opening resumes the current decision, not another conversation. No eligible decision means an explanation of
constraints or unavailable capabilities. TASK-00364 owns actual bounded AFK preparation; UI presence cannot claim it.

Separate Wayfinder resolution from a separately invoked grill and later decomposition. No model answers product,
priority, boundary or risk choices, approves its own findings or invokes guarded lifecycle operations. Show closed
map decisions over all currently known decisions and settled interview points over known required points; explain
new denominator items and distinguish preparation/review from accepted completion. Never infer percentages from
turns, tokens or elapsed time.

Reuse ADR 0003/0004 authority/cache fences and safe rendering. Manual preview edits remain volatile until explicitly
submitted, with leave warnings; reload recovers server candidates, not unsaved keystrokes. Context/authority changes
retire stale private views and cannot revive approval via retained answers.
