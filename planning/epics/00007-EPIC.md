# Coordinate one TASK through implementation

## Destination

Deliver the first production coordinated-execution slice. An authorized human selects one eligible TASK and
confirms **Start coordinated work**; the application atomically revalidates eligibility, exclusively claims that
TASK, creates and dispatches one durable Workflow, and lets a managed Team Lead direct one distinct managed
Software Engineer in a Workflow-owned isolated worktree.

The Software Engineer implements the approved TASK revision through scoped file tools. The Team Lead requests
required checks through permission-gated application operations; trusted infrastructure executes them and prepares
the implementation commit. Engineer submits a complete commit-specific durable handoff. The Workflow then stops
authoritatively at **Awaiting review** with its claim, branch, worktree, Pi sessions, events, observations, evidence, Artifacts, usage, recovery
state, and next human action preserved.

Make current and historical work understandable through the accepted sessions-first Dashboard and an honest
dynamic completion forecast through Awaiting review. Exercise the production capability on one real Fight Agent
OS TASK; do not create a disposable runner, Workflow type, proof endpoint, alternate persistence path, or
certification suite.
