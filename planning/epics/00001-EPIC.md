# Establish project-local planning skills

## Destination

Create the first Fight Agent OS planning skills so future work starts with shared language, durable Markdown records, and explicit handoffs. The first suite covers grill, Wayfinder, research, prototype, EPIC-to-TICKET decomposition, and TICKET-to-TASK decomposition.

## Decisions and exclusions

- Use fresh project-local Pi skills under `.pi/skills/`; do not import the previous Factory workflow suite wholesale.
- Adapt useful ideas from Matt Pocock's public skills while aligning names and outputs to EPIC → TICKET → TASK.
- Use `to-tickets` for creating requirements TICKETs and `to-tasks` for creating implementation TASKs.
- Avoid `specs` and generic `tickets` skill names because they conflict with this repository's planning terms.
- Keep worktree automation, multi-agent orchestration, MySQL observability, and the React planning UI as downstream planning topics.
